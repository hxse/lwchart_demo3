# TQ 逐窗口主连与加权

## 使用场景与设计初衷

同一页面希望部分周期看主连、部分周期看加权。现有页面只有一个 TQ 基础品种，
各窗口仅周期和指标可独立配置，需要增加轻量的逐窗口品种形式选择。
用户输入具体合约时应继续看该合约，不能由本设置推导或查询对应的主连、加权。

下单面板切换品种后继续展示原品种的持仓与清理结果，容易把旧快照当作当前资料。
需要清空这块显示，保持已经发出的撤单及其执行互斥，防止显示重置提前放开开仓。

## 方案对比

直接修改公共品种会同时影响所有窗口；让每个窗口输入完整品种又会重复维护交易所
和品种名。逐窗口保存形式，创建行情身份时替换固定前缀，可以保留公共品种和现有
自选切换，复用已有按完整身份共享的行情流。

## 取舍结论

每个窗口提供跟随品种、主连、加权三个选择，缺省跟随，以保持旧 URL 的行为。
只替换开头的 KQ.m@／KQ.i@，不查后端映射、不推断具体合约、不改变指标算法。
设置放 TQ 来源区域并写入 URL；具体合约时保留选择但忽略转换，切回连续合约后恢复生效。
持仓查询的显示随实际下单身份失效；同品种重开仍保留清理结果，旧身份的晚到响应不恢复显示。
