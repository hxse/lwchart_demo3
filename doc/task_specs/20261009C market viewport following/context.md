# 看盘视窗跟随

## 使用场景与设计初衷

用户查看最新行情时，新 K 线应出现在原来末根的位置，已有 K 线左移一个当前间距，
保留右侧距离。最新蜡烛完整贴边也属于这一状态。右侧存在被完全或部分隐藏的
K 线时，用户正在查看历史；行情追加不应改变其正在查看的时间位置。

当前逻辑以可视逻辑范围右端是否达到末根索引判定跟随。SDK 给每根 K 线分配的
空间包含间隔，蜡烛实体通常更窄，逻辑范围判定可能把完整贴边误判为历史。
原有测试检查逻辑范围及历史锚点，尚不能证明实际绘制边缘和水平移动的精度。

## 方案对比

按右侧留白或整数逻辑索引判定容易实现，但无法准确表达完整贴边与部分裁切的边界。
按 SDK 的实际蜡烛绘制边缘判定可以直接对应用户看到的结果；需要适配内置蜡烛
宽度和画布像素比例，并用真实绘制验证其一致性。

保持当前水平偏移可直接沿用 SDK 的时间轴映射。重新设置整个可视范围会重新
推导柱间距；本任务采用只调整偏移的方式保留用户缩放和小数间距。

## 取舍结论

复用内置蜡烛和既有数据补丁入口，以最新蜡烛完整右边缘是否超出绘图区决定跟随。
几何适配集中在一个模块，记录 SDK 来源；依赖升级时由实际画布测试检出差异。
保持既有历史时间锚点、重载失去锚点后的恢复规则，不新增设置或 URL 参数。
