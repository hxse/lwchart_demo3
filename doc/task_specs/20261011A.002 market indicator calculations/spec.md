# 库计算与末根更新

## 任务边界

以 trading-signals 8.3.0 为首个候选，先完成十一指标可靠性与严格对齐准入，
再将精确锁定的合格官方版本用于生产，建立唯一原生计算适配。
替换 market 的计算状态、数据事件和调用方，改变行情合并为旧末根覆盖加新根追加，
历史异常及缺少旧末根统一进入重新请求 history_bars 的完整重载。

总体契约见 [主任务 spec](<../20261011A unified technical indicators/spec.md>) 的
“所有权与唯一链路”“正常行情与异常重载”和严格对齐要求；定义与参数继承
[前置 spec](<../20261011A.001 indicator metadata contracts/spec.md>)，不复制元数据。
原生执行只绑定 [构造与读取表](<../20261011A.001 indicator metadata contracts/spec_01_native_contract.md>)，
不能另选 MACD 子指标、平滑器或可用状态。
计划计算模块位于 src/indicators/，不是现有公开 SDK。

同时退出 EmaSeries.ts、检查点与 canUpdate、CandleStore.emas、DataChange.emas、
旧 EMA 参数／结果映射副本，迁移 MarketStream、chartData 和所有相关调用及类型。
旧 ema.test.ts／ema-reference.test.ts 的自研算法断言由新库契约测试取代；删除
tests/fixtures/ema-reference.json 与 generate_ema_reference.py，移除有效规范及
使用说明中的旧生成入口。保留这些文件之外仍有独立职责的测试与 fixture。
生成声明和受影响 current spec 同步，历史 task 文档不批量回写。

公开 market 暂时仍只接受 EMA，现有图表沿元数据展示；其 EMA 数值改为库的原生
播种与预热结果。全部十一种计算适配可以由正式离线测试使用，不提前开放未完成
的副图与复合输出。保持取数路由、来源隔离、视窗、自选、配置及部署行为。

停止线：原生库是唯一计算实现；已开放指标严格对齐与可靠性通过；正常／异常数据协议、
原子提交及现有入口回归通过；旧算法与参考生成链路无有效残留。
单指标的原生生命周期或合法边界不通过时，可暂不开放该指标，保留原因与明确
断言的离线最小复现，继续其它指标及整体任务。默认 EMA 和公共链路问题仍阻断；
必需的已开放指标验证不能跳过，也不能留下旧计算作为备用。

## 任务规范

### 准入先于生产迁移

先在离线正式测试中验证候选发行包、构造／输入／读取口径与首根生命周期，
对全部十一指标执行固定已知结果、常量与其他合法边界、恢复和严格对齐。
这些都是本阶段必需准入，不能推迟到显示或集成阶段。
每个候选先精确安装并锁定以供正式测试，生产尚不调用新适配；准入通过后才
切换消费者。测试只使用安装完成的本地依赖，执行期间不访问注册表或外部服务。

完成各指标准入后，切换生产调用并删除旧实现；仅开放通过的指标。
依主任务政策可选用契约一致的较新官方版本，记录实际版本与静态期望来源并
重跑全部准入，不能挑选某版部分指标混用或只重跑曾经失败的指标。
同一个官方版本的单指标失败可暂停该指标支持，不能影响 legacy 的导入数值展示。
默认 EMA 或公共核心契约不能成立时停止；不维护 fork、本地补丁、应用公式或容差。

### 原生计算适配

package.json 固定候选精确版本，bun.lock 冻结依赖；通过准入才成为交付版本。
各指标的原生构造、输入字段、结果
角色、可用状态通过共享定义统一绑定；组合指标直接使用库提供的组成与结果。
不得实现滚动均值、平滑递推、布林标准差、MACD 差值等替代计算公式。
输入转换、时间映射、结果摘取和显示裁剪属于适配，不改变库数值。

每个指标实例拥有独立原生状态，按规范化配置键管理。全量初始化新建实例并依次
输入完整序列；末根覆盖调用 replace，新根逐根调用 add。计算起点只有一根输入
的覆盖遵守原生对应表，换新实例 add 修正后的唯一输入；不请求历史。
不能以展示容量为一误判这个例外，也不能把两根以上的覆盖改成重放。
不得用重建滚动窗口
替代正常增量，不把 replace 实现成追加，也不保留应用侧历史计算状态检查点。

输出按指标实例和角色保存，使用毫秒时间，与显示格式无关。原生无值和数值零
必须区分；warmup／value／undefined 沿主任务及对应表记录，CCI NaN 白名单保留
原始值而不变成错误或零。其他非有限值、不符合契约的结果明确失败。
多输出依据根读取口径记录，MACD 不依据内部 signal 预热拆分可用时刻。

原生输入依赖决定是否更新。某一字段变化不影响对应输入时不调用该指标 replace；
例如纯 volume 更新不应重算这些不依赖 volume 的指标。不能只比较 close 就忽略
high／low 对 ATR、ADX、CCI、ER 的影响；输入依赖使用前置冻结的对应表。

### 合并与完整重载

CandleStore 负责先校验与分类，再计算及提交；MarketStream 负责请求、单飞、取消、
重载状态及错误传播。缺少旧末根的判定必须早于任何行情或指标状态变更。
历史比较和插入判定沿主任务规则，原始行情比较缓存最多五根，与展示裁剪分开。
缓存不是计算检查点，不参与重放，不承诺验证已经不再保留的历史。

正常更新先检查全部重叠历史，再处理旧末根，最后顺序追加。全部检查通过前不改
原生实例。一次事件包含本轮行情及指标对应变化，消费者只接收成功提交的完整
事件；相同批次不产生重复点和不必要的重绘。

历史不一致或缺旧末根记录一次带身份与原因的控制台 WARN，然后在同一请求周期
最多额外获取一次完整数量。完整数据通过校验与全部新实例计算后，行情、输出、
缓存和实例一起提交；不得拿最新五根或现存显示窗口当完整重载结果。

完整取数或响应校验失败，展示保持上一份快照，标记下轮直接完整请求。
任意阶段的计算错误均保留已提交快照、停止此流自动更新，显示指标与失败原因，
不继续使用已推进实例，也不把相同历史反复重载当恢复方案。
移除问题指标、切身份或明确重新加载时从已提交窗口或新完整数据重新初始化；
错误恢复重置全部受污染实例的计算起点。正常配置编辑仍只改变新增／修改实例。
合法 undefined 不停止更新、不请求重载；历史异常仍按既有完整取数协议处理。
取消、旧代次晚到、空数据及非空快照倒退，严格沿主任务失败语义处理。

裁剪不重新初始化原生实例；图表只移除被裁掉的点。增加或修改一个指标只为该
实例从当前显示窗口初始化，未变化实例继续运行。纯样式变化不重新取数或计算。
用统一实例结果替换 EMA 专用 Map 与事件字段，不能同时维护通用状态和旧 emas。

## 公开接口与用户写法

行情 API、配置来源、query 字段及 hash 自选不变。公开 market 当前阶段仍使用：

```text
/?indicators=ema%2C14%3Bema%2C50
```

EMA 显示规则仍来自前置元数据，但数值采用库的原生 EMA；不提供旧 SMA 播种开关。
其他类型的最终公开写法已在主任务冻结，本阶段保留明确的阶段可用范围检查。

下面是必须成立的真实数据流程，其中每个字母代表不同时间的合法 OHLCV：

| 已有／最新响应 | 行为 |
| --- | --- |
| A–E／C–G，C、D 相同 | 校验 C、D；覆盖 E；依次追加 F、G |
| A–E／C、D、F、G | 即使 C、D 重叠，也因缺少 E 请求完整 history_bars |
| A–E／C–G，C 或 D 有差异 | 不处理 E、F、G；警告并重新请求完整 history_bars |
| A–E／相同 C–E | 不重复计算或绘图 |

例如 history_bars=1500，异常响应后的请求数量为“1500 初始、5 更新、1500 重载”。
若重载失败，下轮请求 1500，不再先请求 5；不会在本轮循环请求多个完整窗口。
上述重试只针对取数／校验失败。CCI 显示“未定义”不请求重载；计算错误显示明确
失败并停止自动更新，不能把它当作缺末根异常重试。
没有新增对外计算函数、状态导出／恢复 API 或日志上传服务。

## 测试、验证与阶段过渡

实施必须通过正式 `just check` 与
`just test`；库计算、行情与故障测试均使用本地模拟输入和 MarketSource mock。
测试调用真实库，mock 只替代数据源，不能 mock 指标结果或只验证 mock 自己。

严格对齐参考直接构造原生类，不经过应用的工厂／计算器。每个检查点用最终修正
后的同一起点完整输入新建实例重算，比较各时刻、角色、预热状态和原始数值。
使用 Object.is 或同等严格断言，禁止容差、取整、修正结果及自写指标参考公式。

全部十一种指标及复合输出必须覆盖：

- 初始完整计算、预热前后、边界周期、短窗口及有效零值。
- 同一末根反复 replace，再一次追加多根；小数 OHLCV、固定 seed 及合法时间跳空。
- 仅 close、仅 high／low、仅 volume 改变时，指标输入依赖和输出均符合定义。
- 连续裁剪后仍与同一起点完整重放一致；参考保留起点以来全部输入后裁剪显示。
- 新增／修改／删除指标只影响对应实例；完整重载重置全部参考起点。
- 只有首根时多次覆盖后追加，及显示容量为一但已处理多根时的原生 replace，
  均与从头原生计算严格相同；例外不能扩张到普通尾段更新。
- EMA／DEMA／TEMA 与 MACD 的准确首点，MACD signal 尚未独立预热时三角色仍
  按整体口径可用；ADX 的首根修正影响必须延伸验证到平滑成熟以后。

可靠性准入必须在本阶段完成：

- 每种指标至少一份有来源的固定期望，注明发行版、参数、输入字段、播种／预热
  口径与全部角色；期望不能由被测工厂或适配生成，也不自写指标公式。
- 常量、上涨／下跌、交替、跳空、小数、最短输入、预热前后、周期边界、有效零，
  非法参数／OHLCV 的报错阶段；只对齐同一库不能代替这些可靠性证据。
- CCI 常量 HLC=100 的 NaN 是 undefined，旧末根有限值改为未定义时也正确更新；
  后续变化恢复有限值，原始 NaN、状态和时间严格对齐，不填 0 或发起行情重载。
- ADX 首根替换后的全部成熟结果严格相同；全零波幅及随后正常波幅不污染平滑，
  必须有有限期望和恢复证明。若只此指标失败，保留最小复现并暂不开放此类型。
- 非白名单 NaN、Infinity、缺字段、类型错误和根读取失败不是合法缺口；生产错误
  状态停止自动更新，测试确认没有请求／重载循环以及没有部分提交。

数据协议测试必须证明：

- 缺旧末根但有其他历史交集仍请求完整数量，旧的“任意交集”行为不能通过。
- 历史 OHLCV 任一字段不同、未知历史插入、空更新触发一次完整请求；正常重叠
  不重算历史。WARN 包含必要身份与差异，不包含凭据。
- 显示容量小于五仍检查已经接收且留在比较缓存中的历史；不额外取初始数据。
- 最新响应未通过基础校验不进入计算；完整重载失败、倒退或原生计算失败均不
  提交部分数据。取数／校验失败下轮完整请求，计算错误停止；合法空完整响应
  清空并继续完整请求，只有用户明确恢复才重建错误流的计算状态。
- 单飞、取消、旧身份晚到、重复批次与既有多图身份隔离继续成立。
- 已有行情上新增指标初始化失败同样进入流错误状态，保留旧快照、取消在途请求并停止取数；
  删除失败配置或修正其参数后可恢复，即使删除时已提交的配置没有变化。其他周期继续配置和更新。

已有受影响测试在本阶段同步迁移，不把旧 EMA 断言失败留给后续。共享图表的
historicalUpdate 仍保留独立契约与测试，不能误删；现有精确视窗回归必须通过。
原生库结果失败时提供指标、参数、输入、阶段与具体差异，不能放宽准入条件。

本阶段完成后只有库计算，公开显示仍是 EMA。后续显示阶段启用全部元数据输出并
删除临时可用范围检查与过渡类型；后续集成复核本阶段已准入的可靠性样本及
浏览器链路，完成双入口验收，不首次决定库是否可靠。
严格数值对齐及可靠性均属于本阶段必须完成的条件，不能推迟到最后才判断库能否使用。
所有候选均须有准入结论；失败不是 test.skip。明确拒绝暂不支持类型并检验原因、
恢复条件与最小复现，合格指标继续严格对齐；不因例外留下自研计算或桥接。
