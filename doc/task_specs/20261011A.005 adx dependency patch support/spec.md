# ADX 依赖补丁与计算支持

## 任务边界

在已集成的统一指标链路上，补齐 ADX 的合法零波幅计算与 market 支持。
继承 [主任务](<../20261011A unified technical indicators/spec.md>) 的职责和停止线，
以及 [原生契约](<../20261011A.001 indicator metadata contracts/spec_01_native_contract.md>)、
[计算协议](<../20261011A.002 market indicator calculations/spec.md>) 和
[显示契约](<../20261011A.003 metadata driven indicator charts/spec.md>)。

仅本任务的 DX 零波幅修复允许使用本地依赖补丁；这明确替代前置禁止补丁的对应范围。
仍精确锁定 trading-signals 8.3.0，不升级其他依赖、不复制自研指标、不修改其他指标公式。
原生首根 replace 状态差异继续由已有“实际输入只有一根时重建原生实例”生命周期处理，
本补丁不改变这项协议。配置、默认 EMA、历史校验和完整重载规则保持原约定。

范围包含补丁文件与安装登记、依赖完整性校验、ADX 能力准入、必要离线测试、容器源码输入和当前文档。
不新增设置项、图表特例、在线测试、真实部署、SSH 操作或推送，不改写历史任务设计。
停止线：ADX 固定边界、严格对齐、实际设置与图表、可复现安装及正式构建通过，
原有指标回归通过。无法维持原生状态协议或需要扩大算法补丁时停止，不加容差或回退。

## 任务规范

### 唯一依赖修复

先使用 Bun 正式 patch 流程准备解除缓存硬链接的包副本，再修改和提交补丁。
补丁只更改发行包 `dist/trend/DX/DX.js`，登记在 `package.json.patchedDependencies`，
对应补丁文件和 `bun.lock` 同步跟踪。安装采用冻结锁文件；补丁缺失或无法应用须失败。
不能靠手改 node_modules 作为交付，也不能在运行时 monkey patch 或另写公式。

在原生 DX 已完成本轮 ATR、正负方向移动状态更新且达到可用阶段后，读取这些值。
当且仅当 ATR、平滑正方向移动和平滑负方向移动均严格等于零时，设置 pdi、mdi 为零，
并通过原有 `setResult(0, replace)` 返回零。此检查先于除法执行。
其他输入沿用原生计算，保留预热数量、结果状态、平滑方式及 replace 标志。
不使用 epsilon、非有限结果通用补零或钳制，不将异常数值伪装成合法零。

常量行情在预热结束后 ADX 为有效零，恢复有方向行情后继续正常平滑。
固定小样本：ADX(2, WSMA)，H=L=C 依次为 100、100、100、101、102、103、104，
前两根 warmup，后五根为 0、50、75、87.5、93.75。原有正常行情固定结果保持不变。

### 依赖文件校验

共享校验器属于构建工具，读取实际安装的 trading-signals 版本与补丁后的完整
`dist/trend/DX/DX.js`。版本必须与指标准入锁定版本一致；文件按原始字节计算
SHA-256，与已审核补丁产物的固定指纹严格比较。预期指纹只定义在校验器中，
不能运行时取当前文件生成预期，不能只检查补丁片段或函数关键字。

`just check`、`just test` 在正式检查前调用校验；market dev／build 在配置加载、
监听和编译前调用，legacy build 在编译与复制前调用。全部入口复用同一函数，
容器构建通过同一个 market build 入口执行校验，不维护镜像专用实现。
帮助、停止及消费已有产物的 serve／生产服务不新增 node_modules 要求。

缺少库或 DX 文件、无法读取版本、版本不符、指纹不符均明确失败；CLI 退出 2，
不启动后续步骤，不自动安装、覆盖文件、放行或刷新指纹。错误指出依赖校验阶段，
提示冻结安装恢复；有意改版本或补丁时，先审核变化并通过严格准入，再手动更新
预期指纹。浏览器行情循环不执行文件校验，不引入运行时 Node 文件系统依赖。

### 接入统一范式

移除 ADX 不可计算记录；设置、query 和 TOML 通过已有共享校验开放 `adx,period`。
计算仍为原生 `new ADX(period, WSMA)`，输入 HLC，根 `isStable` 判定可用，
`getResultOrThrow()` 映射到唯一 `value` 输出。其他非有限 ADX 输出仍是计算失败。

显示由已有 ADX 定义和通用展示描述驱动：独立副图、普通数值格式及 25 参考线。
不在 chart、market 或 legacy 新增 ADX 名称分支。参数修改、移除和重加遵守已有实例
生命周期；主题、图例和 legacy 预计算数据继续复用共享链路。

### 构建与部署输入

Containerfile 在冻结安装前复制登记补丁，构建白名单只纳入 package.json 中实际登记
的 `patches/` 普通补丁文件，不遍历或上传未登记文件。补丁路径须为安全的项目内相对
路径，拒绝越界和符号链接。补丁内容参与源码指纹和输入校验。
本地镜像与远程上传复用同一来源；不建立远端专用补丁分支。配置、网络和启动逻辑不变。

## 公开接口与用户写法

沿用统一 DSL，没有新的字段或参数：

```toml
[dashboard]
indicators = ["ema,14", "rsi,14", "adx,14"]
```

```text
/?indicators=ema%2C14%3Brsi%2C14%3Badx%2C14
```

设置指标输入框可填 `ema,14;rsi,14;adx,14`。默认 ADX 周期为 14，最小周期为 2；
`adx,1`、缺参数、非整数周期和重复配置继续在共享参数校验阶段明确拒绝，不能静默删除。
legacy 注记写法和预计算文件不变；本任务不为 legacy 引入实时计算。

## 测试、验证与阶段过渡

使用正式 `just check`、`just test` 和 `just market --build`。离线测试不访问真实行情、
注册表或 SSH；容器输入验证使用既有本地 fixture 和 mock，不启动生产实例。

- 原生 DX／ADX 全零边界、固定恢复值、正常 golden 样本、最短合法周期和默认周期。
- 独立原生全量重放与应用增量严格 Object.is 对齐：初始平盘、转为波动、再次平盘、
  反复末根替换、连续多根追加、展示裁剪和首根替换；值、预热状态和时间都须一致。
- 全十一指标既有可靠性、组合角色、尾段更新、历史异常和原子提交回归。
- 实际 market URL 和设置提交接受 ADX，非法参数保持原配置；真实 SDK 显示独立副图、
  图例和 25 参考线，参数修改与移除重加不会合并副图；浏览器与 Bun 结果严格相同。
- 新临时目录复制登记依赖、锁文件和补丁，离线冻结安装后直接运行原生 ADX，
  同时运行正式文件校验并验证零和固定恢复值；不复用工作区 node_modules 作为重新安装成功的证据。
- 临时依赖副本验证固定指纹正例、版本不符、缺文件、未打补丁和补丁区域外的
  字节变动均按正确错误阶段拒绝。真实 check／test、market dev／build 和 legacy
  build 入口在损坏副本中明确退出，编译、监听和复制未开始；控制入口仍独立可用。
- 构建白名单、指纹和输入副本包含登记补丁，未登记文件不进入上传，缺失／非法路径
  明确失败；Containerfile 先复制补丁再安装，既有本地／远程 mock 部署回归保持通过。
- 静态检查和正式 market 产物完成；当前规范与用户说明明确唯一补丁例外和 ADX 写法。

无桥接和阶段性必需失败；实现后直接开放 ADX，不保留旧不可用记录或备用算法。
未来切换官方修复版本必须重新通过严格准入，再同时退出补丁、登记及构建专用输入。
