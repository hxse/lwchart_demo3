# market 主图默认占比

## 任务边界

为 market 增加公共 main_pane_ratio 设置、TOML 默认值与 query 绑定，替代 market
固定五比一的默认高度策略。一个页面所有看盘窗口采用同一占比，各窗口分别根据
实际配置的副图数量均分剩余空间；不新增单窗口配置或指标专属高度参数。

手动拖动仅是临时布局，不修改配置、query 或 hash。保留现有分隔线与主题、行情
更新、图表实例、历史视口、两个数据源与自选行为。legacy 保持既有首次权重策略，
不为该入口增加占比设置。共享图表只处理通用 Pane 与权重，不识别具体指标名。

范围包括配置和 UI、图表描述及权重应用、必要生成声明、离线回归、公共配置模板、
受影响的 current spec／guide。私有配置不用改，新字段缺省自动使用默认值。
不改指标计算、数据协议、后端接口、依赖版本或 ADX 补丁，不实际部署或推送。
停止线：默认占比、query／设置往返、临时拖动保持、结构增删、双入口回归与正式
检查构建均通过。不能通过重复创建图表、重算指标、放宽参数或忽略验证完成任务。

## 任务规范

### 配置与校验

main_pane_ratio 属于公共显示参数，内部为有限 number，必须满足 0 < r < 1。
唯一默认值为 0.7，TOML／runtime 缺省时由共享归一入口补齐；显式 null、文本、
boolean、NaN、Infinity、0、1 或越界值明确拒绝，不夹值或回退。
query 解析数字文本后复用同一数值校验，接受十进制小数及十进制指数写法；
拒绝空值、重复键、空白、十六进制及不可表示的数值。序列化采用规范化数字文本。

设置新增“主图占比”数值输入，位于公共设置框内。编辑只改变草稿；应用成功后
同步设置与 query，取消／Esc 丢弃，浏览器前进后退复用现有导航。配置保留双方来源
身份和 hash；来源切换、自选点击及布局修改都保留该公共参数。
只修改占比不重新请求历史、不计算指标、不更换现有行情流或图表实例。

### 权重描述与应用

market 通过指标定义的 placement 形成 Pane：叠加主图的均线和布林带不计副图；
每个独立指标配置算一个副图，复合输出仍共用一个 Pane。预热或未定义不删除 Pane。
有 N 个副图时，主图权重为 r，每个副图为 (1-r)/N，同 Pane 的系列使用相同权重。
N=0 时唯一 Pane 权重为一，占全部绘图空间；该情况仍保留设置中的 r。

权重应用于扣除时间轴和分隔线后的可用绘图高度；实际像素遵守 SDK 的舍入及最小
绘图高度，极小比例不意味着隐藏或删除 Pane，不额外修改 SDK 或限制合法比例。

共享图表增加通用 paneWeightMode：initial 保留首次初始化权重；preset 将全部
配置权重视作一个布局预设。默认 initial，market 显式使用 preset。权重职责在
共享 Pane 模块，使用实际 Pane 身份及已应用的配置权重记录预设，不能把 SDK
当前拖动后的伸展因子当作新的配置值。

preset 仅在首次应用、权重向量改变或 Pane 身份／数量改变时统一设置全部权重，
包括主图；不按输出角色重复设置。同预设的数据、主题、时区、同数量参数替换／
重排及相同设置应用不会重置手动高度。改变占比、增删副图或重建图表后重新应用
默认布局。手动拖动不更新预设记录，不新增回写配置或 URL 的监听。

## 公开接口与用户写法

```toml
[dashboard]
main_pane_ratio = 0.7
indicators = ["rsi,14", "macd,12,26,9"]
```

```text
http://127.0.0.1:5174/?timeframes=30m&indicators=rsi%2C14%3Bmacd%2C12%2C26%2C9&main_pane_ratio=0.7
```

此配置主图默认七成，RSI 和 MACD 副图各约一成半。设置“主图占比”填 0.6 并
应用后主图六成、两个副图各两成；拖动后输入框和 URL 仍保存 0.6，刷新恢复预设。
`main_pane_ratio=0`、`1`、`NaN`、`0x1`、空值和重复键都明确报错；非法菜单
提交保留原设置、URL 和图表。完整 query 增为十五字段，不增加 hash 参数。

共享 LWChart 的可选 paneWeightMode 为 'initial' | 'preset'，仍从现有
SeriesConfig.paneWeight 读取权重，不新增指标名称判断或单独的像素高度 API。
默认值保持 legacy 既有行为，生成声明必须表达该参数及导出的 PaneWeightMode 类型。

## 测试、验证与阶段过渡

使用正式 `just check`、`just test`、`just market --build`。legacy 构建与声明消费
由既有离线浏览器入口完成，使用临时目标，不写用户 Notebook 目录，不访问外网。

- 配置默认与 TOML、local／remote 覆盖、合法小数／指数的 query 往返、非法类型／
  边界／空值／重复键、来源和自选保持、完整十五字段；缺省旧私有配置仍能归一。
- 元数据计算零／一／多副图及复合角色的权重，无硬编码名称，预热／无值仍参与。
- 真实共享注册流程在 DOM 前完成预设，变化时统一更新全部 Pane；同预设保持
  手动因子，参数替换、重排、结构增删和清理无孤立 Pane；initial 模式回归。
- 实际浏览器布局按绘图高度验证比例与副图均分，允许仅 SDK 像素舍入差异。
  菜单草稿／取消／应用、导航、刷新恢复，非法 URL 在取数前拒绝并可修正。
- 真实鼠标拖动后配置与 URL 不变，行情／主题／时区和同数量参数变化保留临时
  高度；比例变化和增删副图恢复预设，主图无副图占满；请求数量和画布身份保持。
- 同一页面多窗口共用比例但不共用临时拖动，旧 Notebook／文件图表、生成声明
  消费和已准入指标回归通过；原 market 固定五比一策略退出，无新旧平行布局。

无阶段桥接、接受的必需失败或新增在线验证；达到本任务停止线后完成交付。
