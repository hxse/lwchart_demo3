# 元数据驱动的双入口显示

## 使用场景与设计初衷

十一种指标既有价格叠加线，也有独立副图和多输出。若图表继续认识 EMA、RSI、
MACD 等名称，新增指标仍须同时修改共享图表及两个入口，无法统一维护。
legacy 已有文件中的指标数值，复用的重点是如何显示，不是重新计算导入数据。

## 方案对比

在两个入口分别生成参考线与样式，只能共用底层绘图库，不能共用指标知识。
让 legacy 根据列名猜指标，也不能可靠区分参数、输出角色和同类多实例。
共享展示描述加可选明确注记，既可复用元数据，也可保留普通文件系列与覆盖配置。

## 取舍结论

指标模块生成通用显示描述，图表按描述管理生命周期。market 使用库计算结果；
legacy 使用导入列，两者只在数据来源与明确覆盖处适配，不复制显示规则。
本阶段同时开放全部指标、退出 EMA 临时范围，并完成真实交互及副图验证。
完整契约见 [主任务 spec](<../20261011A unified technical indicators/spec.md>)，
计算状态继承 [前置 spec](<../20261011A.002 market indicator calculations/spec.md>)。

market 当前只有配置编辑，标签不是显隐控件；本阶段保持这个范围，删除配置就
释放实例及独占副图，重新添加重新播种。legacy 的 id 是文件组身份，可区分同参
多组；显式参考线含隐藏项先覆盖默认线，显式系列颜色先于自动逐点颜色。
