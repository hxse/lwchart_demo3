# 看盘内存优化

## 任务边界

在当前任务 change 中完成四项工作：服务端与绘图库解耦、行情校验复制优化、
Bun 默认／--smol 对照、浏览器行情／指标／图表时间线的分配优化。同步受影响的
current spec 和命令说明；保存离线测量入口，不保存本轮执行日志或验收文档。

保持全部 HTTP、TOML、URL、Notebook 和图表公开接口，保持指标算法、精度、
窗口容量、五根轮询、刷新频率、错误语义、缺口绘制和视口跟随行为。不减少校验，
不增加长期缓存、第三方依赖或兼容双轨，不调整正在运行的容器及真实后端。
临时基线、fixture 构建及测量配置仅放系统临时目录，结束后清理所属资源。

停止线为：四项均完成实现或基于测量作出取舍；行为验证通过；优化前后及
--smol 的同负载对照可复现。无可靠收益的复杂改造不保留；不能为了降低指标
改写监控口径、强制生产 GC 或改变业务设置。

## 任务规范

### 服务端依赖与行情所有权

时区校验独立于浏览器格式化和绘图库，配置及浏览器使用同一校验函数；迁移
原 time.ts 中的校验导出及全部调用，不保留同职责转发。生产打包阻止意外引入
lightweight-charts／fancy-canvas／Svelte／指标计算库等浏览器实现。

行情校验只验证并借用输入数组，不修改、补值或排序；TQ 必须先精确解析纳秒
整数，再创建一次六列数组并复用校验。数量、有限值、OHLC、非负成交量、严格
升序、CCXT 时间域及完成状态、TQ 无损时间转换与既有失败语义全部保留。
调用者不得修改借用的数据；CandleStore 在接收行情时复制取得所有权，已发布的
行情与指标快照不能被后续更新或输入方修改污染。

### 浏览器更新

行情窗口通过已排序时间查找和至多五根 recent 核对历史，不再每轮建立整窗 Map。
无变化时仍吸收有效 recent 比较信息，但不复制整窗或重新发布指标快照。
初始化各指标可共享同一批只读输入，不能改变计算起点或累计输入数量。

指标角色数组仅在已被快照发布且需要改变时复制；批内尚未发布的数据可复用。
全部角色计算成功后才写入点；历史快照、失败保留、CCI undefined、裁剪前一个
参考值及原生严格结果保持。不得用原地改写已发布数组换取低内存。

图表增量预校验直接查询已提交时间线，避免为历史存在性重复构造数组／Set／Map。
整批非法输入在触碰 SDK 和提交时间线前失败；普通更新只提交变更点，完整替换
及历史缺口仍按既有 setData 规则处理。内部时间线由绘图链独占，不作为对外快照；
只有 SDK 接受对应系列更新后才提交。删除系列清理索引；没有内部缺口的折线不
构造分段数组，有缺口时保留完整分段绘制。缺口语义和视口规则不变。

### 性能取舍

使用相同 Bun、依赖、硬件和确定性离线输入，分别测量既有与优化后产物。服务端
采用独立进程、临时端口和模拟鉴权后端，覆盖两来源、四路并发、初始 1000 根、
5 根轮询及最大 10000 根重载；记录 RSS、匿名内存、峰值、空闲回落与请求延迟。
生产代码不增加统计接口或 GC 调用，生产启动保持 Bun 默认模式。默认及 --smol
至少各三次交错对照；小堆模式仅保留为诊断候选，不进入生产入口。

浏览器使用已安装 Chromium、真实 SDK 和正式数据／指标／绘图链，比较四窗口、
1000／10000 根、重复批次、末根覆盖及追加裁剪。记录耗时、JS 堆及采样分配量；
测量所需显式 GC 只在隔离浏览器的阶段边界执行，分配量标为采样估计。
保留终态校验，不能仅压测无效调用。报告中区分服务端 RSS 与浏览器堆、吞吐负载
与真实五秒节拍，不承诺固定节省比例。

## 公开接口与用户写法

看盘、部署、HTTP 和用户配置无变化。新增显式离线诊断入口：

```bash
just benchmark-memory --baseline=/tmp/lwchart-memory-baseline --runs=3
```

baseline 指向已保存的优化前源码根，必须含 src、对应 dist-market、package.json、config.example.toml
及可解析的同版本依赖；当前工作区也必须已有配套 dist-market。入口不隐式下载、
安装或构建业务产物，不连接真实服务；只为浏览器诊断构建临时 fixture。
runs 为 1..10 的整数，默认 3；正式取舍至少三次。缺基线、产物或非法参数明确失败。
输出结构化测量数据到标准输出，不默认保存报告，不进入默认 just test。

## 测试、验证与阶段过渡

必须运行 just check、just test、just market --build 以及上述离线对照入口。
just test 覆盖两来源鉴权与错误、行校验、十一指标严格重放、窗口和快照隔离、
完整批次错误、历史修正、缺口绘制、视口跟随、共享流、配置切换及旧 Notebook。
补充输入修改隔离、已发布快照跨多次增量／裁剪不变、无变化批次仍学习 recent、
图表非法后续系列不修改先前系列和索引的回归。生产构建须阻止浏览器依赖渗入。

本任务无阶段性失败或暂不可用入口；不修改依赖及指标公式。容器与生产浏览器
fixture 都保持默认启动方式，诊断覆盖 --smol 下的两来源服务。性能不设硬件相关的测试通过阈值，
以重复测量和正确性共同决定取舍；没有明确收益不引入更复杂存储结构。
