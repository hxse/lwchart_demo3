# 实时多周期看盘

## 启动

使用宿主 Bun 和 Just，先安装锁定的依赖：

```bash
bun install --frozen-lockfile
```

没有配置时复制 config.example.toml 为 config.toml，填写 backend.username／password。
这是 ccxt-proxy2 后端登录账号，默认后端 http://127.0.0.1:5123。

新版配置中 [dashboard] 维护显示设置，[ccxt] 和 [tq] 维护各来源默认品种。
TQ 默认 KQ.m@SHFE.rb；[tq] 不填写天勤账号，仍用 backend 的鉴权。
旧配置需将 dashboard 的交易所／市场／环境／品种移到 [ccxt]，增加 source、timezone
和 [tq]，删除 incremental_bars／max_catchup_pages；按最新模板核对，保留原凭据。

配置修改后重启：

```bash
just market --stop
just market
```

打开 http://127.0.0.1:5174/。默认 Binance BTC/USDT:USDT、深色四图：
左上 30m、右上 4h、左下日线、右下周线；EMA14／50／100 为橙／绿／蓝。
每 5 秒更新，鼠标时间跨周期联动；看历史时不会被更新拉回末尾。

按钮栏齿轮展开悬浮设置。修改先留在草稿，**点击“应用”才更新图表与地址**；
取消、关闭、Esc 或点击设置外部都会丢弃修改并收起。原行情在编辑期间继续更新。
“恢复默认值”将服务启动时的默认设置填入草稿，点击应用后生效；不清空自选列表。
浏览器前进／后退会同步图表和打开中的设置，首次打开自动补全完整参数。

5174 被占用时用上述 stop 停止本项目对应实例；自定义配置用
`just market --stop --config=配置路径`，不会按端口停止其它程序。

## 数据源与 URL

设置上方为 CCXT／TQ 两个 Tab，各自填写品种与内部参数；来源区域用细框包围，下方公共设置另用细框包围，配色跟随主题。
切 Tab 保留两边编辑，点击应用后才切换实际行情。CCXT 的市场是现货／合约，
环境是实盘／模拟盘；TQ 不使用这些参数。后端需启用对应服务并授予当前账号行情权限。

query 同时保存双方参数，source 选择当前来源。两边共用布局、周期、公共指标及窗口覆盖、历史数量、
更新间隔、主题与时区；切到 TQ 再切回来仍保留之前的 CCXT 选项。
旧 URL 中裸写的 symbol／exchange_name／market／is_live 要分别改为 ccxt.* 或 tq.symbol。

TQ 品种框下面可分别为每个窗口选择“跟随品种”“主连”“加权”，默认跟随输入。
只有开头的 KQ.m@／KQ.i@ 会转换，交易所和品种后缀保持；例如输入 KQ.m@SHFE.rb，
某窗口选加权后，该窗口请求并显示 KQ.i@SHFE.rb。选择主连也能把 KQ.i@ 转回 KQ.m@。
具体合约如 SHFE.rb2701 始终保持原样，界面提示设置不生效，但保留选择；切回连续
品种时继续生效。无需查询主连映射，图表标题显示各窗口实际请求的品种。

应用后写入 URL，取消不生效；恢复默认值将各窗口改回跟随。选择跟随窗口位置，
不跟随周期；缩小布局删除多余选择，新增窗口跟随。切来源、自选或具体合约保留
其余选择，书签、刷新及浏览器前后退均能恢复，不写入 TOML 或浏览器缓存。
例如下面让 30m 看主连、4h 看加权，缺少参数的窗口跟随基础品种：

```text
http://127.0.0.1:5174/?source=tq&tq.symbol=KQ.m%40SHFE.rb&timeframes=30m,4h&chart.2.tq_series=index
```

`chart.N.tq_series` 只接受 main 或 index；跟随时省略，不能写 inherit。窗口编号必须
在当前布局内，非法值报错。相同实际品种和周期仍共享请求，主连与加权各自读取。

```text
http://127.0.0.1:5174/?ccxt.symbol=ETH%2FUSDT%3AUSDT
http://127.0.0.1:5174/?source=tq&tq.symbol=KQ.m%40SHFE.rb&history_bars=1500
http://127.0.0.1:5174/?layout=1x2&timeframes=30m,4h&indicators=none
http://127.0.0.1:5174/?history_bars=500&theme=light&timezone=Asia%2FShanghai
http://127.0.0.1:5174/?timeframes=30m&indicators=rsi%2C14%3Bmacd%2C12%2C26%2C9&main_pane_ratio=0.7
```

layout 为行×列，支持 1x1、1x2、2x1、1x3、3x1、2x2。仅写周期按数量推断布局；
显式布局与周期数量必须一致。技术指标用紧凑写法，多个用分号连接；none 表示无指标。
支持 sma、ema、dema、tema、rsi、cci、macd、atr、adx、er、bbands，非法参数明确报错。
示例为 ema,14;rsi,14;macd,12,26,9;adx,14;bbands,20,2，完整参数见
[指标规范](../current_specs/indicators.md)。
缺省字段从启动配置补全。完整规则见 [看盘规范](../current_specs/crypto_dashboard.md)。

窗口设置用 Tab 选择位置，分别配置周期和指标模式：继承公共、独立配置、无指标。
缺省继承公共“技术指标”；独立输入沿用同一写法，即使暂时与公共相同也保持独立。
URL 使用 `chart.1.indicators` 等窗口位置参数，缺参数继承、none 明确关闭：

```text
http://127.0.0.1:5174/?timeframes=30m,30m&indicators=ema,14&chart.1.indicators=rsi,14&chart.2.indicators=macd,12,26,9
```

这两个窗口共享三十分钟行情，分别显示 RSI 和 MACD；只改指标不重新请求历史。
配置跟随窗口位置，减少布局删除多余覆盖，新增窗口继承；保存书签或前进后退
恢复组合。TOML 继续只提供公共默认指标，不保存逐窗口覆盖。

公共设置的“主图占比”使用大于 0、小于 1 的小数，默认 0.7。例如 RSI 与 MACD
两个副图时，主图默认七成，两个副图各约一成半；无副图时主图占满。
可在 `[dashboard]` 写 `main_pane_ratio = 0.7`，设置与 query 也可覆盖。
该比例是默认布局：拖动分隔线只临时调整当前窗口，不修改设置或地址，行情和
主题更新保留手动高度。改变占比、增删副图或刷新后恢复默认分配；多窗口拖动互不影响。

## 自选与书签

一个页面一份设置、一个自选列表。保存完整 URL 为浏览器书签即可保存这份组合，
多个设置／自选组合保存成多个书签。页面修改不写入本地配置或浏览器存储。

```text
http://127.0.0.1:5174/?history_bars=1500#binance,BTC/USDT:USDT;binance,ETH/USDT:USDT;tq,KQ.m@SHFE.rb
```

hash 中用“来源,品种”填写一项，分号分隔，支持 Binance、Kraken、TQ 混合排序。
hash 不发送到服务端。没有列表且未平铺时点击右侧小按钮新建；已有列表或开启平铺时点击展开／折叠。
鼠标进入小按钮后在其下方出现上一项／下一项，在按钮和控制附近 12px 内保持，离开立即消失。
也可用展开面板标题的按钮导航。
当前品种不在列表时，下一项从第一项开始，上一项从最后项开始；首尾循环。
点击条目只更新当前来源、交易所和品种，保留全部其它设置和整个列表。默认未锁定，选择成功或点击外部自动收起。
标题的锁定按钮可保持列表展开，选择品种和点击外部均不收起；仍可手动折叠。
锁定状态不进入 URL，刷新恢复未锁定。
展开列表时自动将当前项尽量滚到中间，首尾停在顶部／底部。

面板“编辑自选”打开独立弹窗，支持新增、修改、删除、拖拽及上下按钮排序。
保存只更新 URL 的 hash，当前品种、设置和行情保持不变；删除当前品种条目也不切换。
编辑弹窗的“清空全部”一次清空草稿，点击“保存自选”后才生效；取消可放弃清空。
清空且未平铺时移除 hash；开启平铺则保留模式。关闭／取消／Esc 丢弃编辑；浏览器前进／后退同步地址。
完整编码 URL 上限为 8192 字符，超限提交会弹窗提示并保留编辑，建议缩短或分成多个书签。

## 按钮栏位置

按钮栏默认在右侧，实际占位 42px，图表填满剩余区域。设置的公共参数“按钮栏位置”
可选上、下、左、右，点击应用才生效；左右竖排，上下横排，位置保存在 query。
例如 http://127.0.0.1:5174/?dock_position=left 。URL 未填写时采用启动默认值，默认 right。
设置和自选展开面板继续悬浮，贴近按钮向图表展开；自选鼠标控制仍是悬浮按钮。

## 平铺按钮栏

在自选面板标题点击平铺按钮，可以将上箭头、下箭头、编辑和每个候选放进实际占位按钮栏。
设置、下单、列表入口依次排列，每个按钮及平铺按钮统一 32×30px；列表入口继续打开悬浮面板。
平铺内容超出按钮栏可用空间时出现细滚动条，不超出则没有滚动条。
Binance／Kraken 显示 / 前的名称（BTC），TQ 显示最后一个 . 后的名称（rb）；其它情况
显示完整品种，长名称可悬浮查看完整来源与品种。点击仍按完整身份切换。

模式默认关闭，开启后写入 hash，可随书签保存；编辑列表会保留模式，前进／后退也同步。

```text
http://127.0.0.1:5174/?history_bars=1500#flat=true;binance,BTC/USDT:USDT;kraken,ETH/USD;tq,KQ.m@SHFE.rb
```

平铺模式与锁定相互独立：平铺绑定 hash，锁定不保存到 URL。清空列表后仍可用编辑入口
添加候选，或用原自选按钮展开面板关闭平铺。模式切换不改变当前设置或重新请求行情。

## 手动下单

按钮栏的“单”打开下单面板；关闭和 Esc 直接收起，不再询问。参数和未确认草稿
会留在当前页面内，重新打开原样恢复。当前图表仅在首次打开时提供默认品种
和所有窗口中的最小周期，品种与周期都能独立修改。交易所和实盘／模拟盘继承
打开时的图表，只读显示；请先看清面板顶部的环境。

内部模式 Tab 当前只有“固定风险金额＋ATR”，采用市价入场。默认 ATR14、风险
金额 1、止损 2 ATR、两项容差各 5%、止盈距离为止损距离的 2 倍。风险币种随
品种报价币固定，BTC/USDT:USDT 为 USDT，BTC/USD:USD 为 USD。

参数区使用紧凑布局，参数、参考、日志三个区域点击标题可分别折叠。编辑后点
“确认”使参数生效，或点“取消”恢复上次确认的参数；有未确认修改时，下单、
强制刷新、查询持仓和查询结果都不可用，手动把数值改回去也须确认或取消。
数字框右侧上下箭头每次加／减 1，也支持键盘上下键；例如 1.5 可加到 2.5。
点击数字框使其获得焦点后，在框内滚轮上滚加 1、下滚减 1；未聚焦时滚轮只滚动
面板。空值或无法解析的数字需先补全。微调后仍须确认或取消，范围错误在确认时提示。
参考区分“做多参考”“做空参考”两个 Tab，首次默认做多，同页记住选择。
核对当前方向的数量、仓位名义价值、触发价格、费用、预计含费风险和误差，再点击“做多”或
“做空”。弹窗核对品种、实盘／模拟盘、方向、仓位名义价值、预计含费风险和预计止盈净收益，
点击“确认做多／确认做空”才下单；
取消或 Esc 只关闭确认框，不提交入场；已经开始的条件单清理仍会继续。弹窗期间参考继续刷新，按最终确认时的最新
有效参考提交。行情／ATR／费率缺失或容差无解时不能提交。
参考区有两个默认开启的勾选项：“空仓时清理只减仓条件单”和“下单前自动查询”。
点击“查询并清理”会先查当前下单品种；确认空仓且没有开仓挂单时，清理明确只减仓
的条件单。普通减仓限价单保留；资料不足、数量未知、有仓位或有开仓挂单时跳过并提示。
可能清理其他客户端创建的合格条件单，结果逐笔显示，失败不会自动重试。

自动查询开启时，点击做多／做空即打开确认框并执行同一查询，显示仓位及清理结果。
清理进行中须等待结束后才能确认入场；纯查询等待或失败不阻止确认。
取消下单不会恢复已经撤掉的条件单。关闭面板或切品种也不会停止已发起清理，
同品种关闭重开保留最近清理结果。切换下单品种／交易身份后清空这块持仓和清理显示，
切回也不会恢复，需重新查询；面板关闭期间换品种同样清空。清理在途时只提示上一
品种的清理尚未结束，结束前本页不能开新仓；晚到结果不会重新显示。原下单日志保留。
关闭清理选项后按钮为“查询持仓”，只读快照会在关闭或切品种时清空。
关闭自动查询后，仅手动按钮执行，确认框不显示持仓。打开面板、ticker、强制刷新
和改勾选均不会触发清理。两项选择只在本页记住，参数重置不改变它们，另一个 tab 独立。
已有同品种仓位可能因下单而增加、合并或抵销。
止盈倍数是价格距离倍数，扣费后净收益会另外显示。

仓位名义价值表示这次数量按入场价折合多少报价币，计算包含合约乘数。例如
2.892 XAG 按 57.09 USDT 计算为 165.10428 USDT；USD 品种则显示 USD。
它不是保证金，也不代表交易所的名义金额预检已通过。

切换图表品种时，悬浮面板收起，平铺面板保持显示并加载新品种；两种形式都只更新
记住的品种及交易身份，其他参数和未确认状态保留。
例如风险金额 1 已确认，改为 2 尚未确认就切 ETH，再打开仍是 ETH、2、待确认；
取消恢复 ETH、1。各品种共用参数，普通关闭重开也会保留手填的下单品种。
“重置默认值”将当前品种、最小周期和默认风险参数填入草稿，点击确认后生效。

标题中的“平铺／悬浮”按钮切换显示形式；平铺在图表与右侧按钮栏之间占位，关闭
后释放空间。平铺时点击图表、切品种或打开设置都不会收起面板；设置显示在其上方，
应用、取消或按 Esc 关闭设置不会关闭平铺面板。悬浮时外部点击仍关闭，两种形式均记住参数。
看盘设置中可调整“下单面板布局”“平铺下单面板宽度（px）”和“悬浮下单面板宽度（px）”。
三个显示值绑定 URL，两种宽度独立保存，例如：
`?order_panel_layout=inline&order_panel_inline_width=230&order_panel_floating_width=480`。
默认悬浮，两种宽度均为 230px，参数保持两列，数字输入框紧凑排列，不随面板拉长；小屏限制
实际显示宽度，不更改设定值。
旧 URL／TOML 的 order_panel_width 已退出，请替换为上面的两项宽度。旧 URL 报错时
也可打开看盘设置，“恢复默认值”后应用，以生成新的完整 URL。

做多／做空参考中的“画线示例”会在各周期主图画出该方向的参考开仓、止损和
止盈线，随参考价格更新；原按钮随后变为“取消示例”，再点即可清除。切换多空
Tab 会清除旧方向的示例，新方向需重新点击“画线示例”。
按钮右侧下拉菜单可多选“止盈线显示”“止损线显示”“仓位线显示”，默认全选；
仓位线指参考入场价。已开启时修改勾选立即生效，全部不选暂时隐藏全部线；
选项会在本页记住，关闭重开或换品种仍保留，重新载入页面恢复全选。只改显示，
不影响下单价格或计算；关闭面板后仍需重新点击主按钮开启示例。
标签放在图内左侧，简写为“多入／多损／多盈”或“空入／空损／空盈”，并显示价格；
相近标签会错开，以短引线对应原价格，右侧不再显示这些示例标签。
只有下单与图表完整交易身份一致、参数已确认且参考有效时可开启。编辑或资料
暂时失效时隐藏；关闭面板、切品种、下单或主动取消后，须重新点按钮才会显示。
自动价格轴会容纳示例线；时间轴位置和手动价格轴保持。这些线不代表已挂单。

支持 Binance 线性永续实盘／模拟盘及 Kraken 线性永续实盘。现货和 Kraken 模拟盘
暂不支持，TQ 面板显示“待实现”。Kraken 的账户费率要求 ccxt-proxy2 配置
`kraken.fee_lookup`，使用当前交易账户的只读 Spot 费用查询凭据；本项目不保存
交易所密钥，也不允许用默认费率代替查询失败。

打开时立即取报价，之后每秒单飞刷新；关闭即停止面板报价请求。ATR 复用已有
算法并包含未收盘末根，不受每秒 ticker 节拍影响。面板不改图表品种、地址或书签。
参数、草稿、折叠状态及最近一轮结果只在本页内存保留，不使用浏览器缓存。
不同 tab 独立；整页刷新或关闭 tab 后清空。刷新后仅 URL 中的布局和宽度可恢复。

“强制刷新”旁显示距离上次成功取得 ticker 的秒数；刷新失败不会把计时归零。
按钮会刷新当前已确认品种的报价、市场资料、费率及行情，每次点击后冷却 5 秒，
请求未结束也不能再次点击。自动报价继续每秒更新，折叠区域不会停止刷新。

未知额度约束或账户模式会提示，交易所最终接受或拒绝；已知不兼容、精度错误
和风险容差仍严格拦截。不做余额／保证金预检，资金不足由交易所拒单。

流程先市价入场并核实实际成交，再并发提交止损和止盈。部分成交只保护确认的
部分，不自动补仓。入场、止损、止盈分别显示成功、失败或未知；“查询结果”
只读取当前事实，保留最初错误，不补挂、不平仓、不重复入场。关闭面板不会取消
已经提交的这一轮，服务退出则不保证继续完成。

日志中的“本轮成交估算（提交时）”同样显示仓位名义价值、预计含费风险和预计
止盈净收益，按本轮实际成交数量与均价计算；部分成交只计算成交部分。后续报价
或“查询结果”不会改写它，也不代表账户总仓位或已实现利润。没有可用成交计划
时会提示暂无估算，不沿用当前参考值。

止损止盈不是 OCO，一张触发后另一张需要自行管理；同品种原仓也可能合并或
抵销。风险是含预计手续费的估算，不包含滑点、资金费和未来费率变化。结果未知
或保护失败时，先核对交易所订单和持仓，再决定下一步。

## 时间与更新

左上角图例显示鼠标对应 K 线的开盘时间、OHLC、成交量 V 和已配置指标。
均线、布林带叠加主图；RSI、CCI、MACD、ATR、ER 位于独立副图，MACD 两线一柱
同组。可拖动副图分隔线调整高度。配置列表删除指标会释放实例与独占副图，
再添加重新初始化；标签不承担临时显隐操作。CCI 平盘未定义时显示缺口，不补零。
显示时区默认 local，跟随浏览器；也可填 UTC、Asia/Shanghai、America/New_York 等。
图例、横轴和光标时间使用同一时区。原始数据始终是 UTC 时间戳，显示时区不会
改变行情、指标计算或光标匹配；切换时区不重新取行情。

初始每周期请求最新 1000 根，历史数量可在设置或 URL 修改，范围 1..10000。
历史不足显示实际返回数量，EMA 不足预热不伪造线段。
每轮请求最新 5 根，包含旧末根且更早重叠历史相同时，覆盖末根并追加；
缺少旧末根或历史有差异时，警告并重新请求完整最新窗口。

最新 K 线在右侧完整显示时自动跟随，完整贴边也算；新增一根时已有 K 线左移
一个当前间距，右侧距离保持。拖动后只要右侧还有部分或整根 K 线被隐藏，行情
更新就保持正在查看的历史位置。拖回完整显示末根后恢复跟随；价格更新不平移。
完整重载成功后丢弃旧历史；网络错误先保留旧画面，下轮继续，不在一轮里反复请求。
期货午休、周末、节假日不靠固定周期长度判成数据缺失。

保留数量是滚动上限，超过后裁掉最早的 K 线。EMA 使用 trading-signals 的原生
递推与预热，裁剪保持连续状态；完整重载或新增指标从相应已加载历史初始化。
计算错误会保留旧画面并暂停该图自动更新，移除问题指标或刷新后重试。

前端同时发起不同周期的请求，每图返回后立即显示。后端／交易所等待可能不同，
TQ 后端也有两路窗口限制，因此并发不等于同时显示。
较大的周线数量可能被后端拒绝，前端如实显示错误，不偷偷减少数量或换起点路由。
Network 响应头 Server-Timing 的 upstream 和 local 可以区分后端等待与本地处理耗时。

图表上下边距为 3%，均线不扩大可见蜡烛的 high／low 范围，布林带上下轨参与缩放。

本地与 ssh rn 的容器运行及配置覆盖见 [部署指南](deployment.md)。
