# 指标对齐与集成验收

## 任务边界

复核十一候选的逐项结论及已准入指标的可靠性样本，完成真实浏览器及双入口集成验收，
检查旧算法、显示硬编码和阶段桥接已退出。只补齐既定契约需要的测试、fixture、
范围内缺陷修复及有效规范／使用说明，不新增指标类型、公式、线上数据源或 API。

继承 [主任务 spec](<../20261011A unified technical indicators/spec.md>) 的最终契约，
[计算 spec](<../20261011A.002 market indicator calculations/spec.md>) 的原生准入与行情协议，
以及 [显示 spec](<../20261011A.003 metadata driven indicator charts/spec.md>) 的用户写法与
生命周期。前置必须已完成各自必需验证；本任务不接受前置故意保留的失败。
构造与结果读取采用 [唯一对应表](<../20261011A.001 indicator metadata contracts/spec_01_native_contract.md>)，
不在本阶段另选子指标或预热口径。

测试使用前置已准入且精确锁定的 trading-signals 官方发行版与本地 fixture，
不新增在线测试、不接真实交易所、
不 SSH 部署、不启动生产 Podman 实例、不修改用户真实 Notebook 导出目录。
库可靠性检查不能引入自写指标 oracle、旧 SMA 播种参考生成器或生产回退算法。

停止线：已开放指标及其全部角色、严格数值、可靠性样本、公开写法、两入口、正式
构建及遗留退出条件均满足；每个限制与警告有明确结论，没有未解释异常跳过。
未对齐、不可复现参考、非白名单非有限结果、遗漏公开契约或必须验证失败阻断交付。

## 任务规范

### 严格对齐与参考起点

参考独立直接创建原生库实例，不调用应用的工厂、结果转换或计算引擎生成期望。
输入字段及构造参数须符合锁定版本和指标定义；参考不能复用被测适配的错误映射。
指标实例与角色逐个比较，不能用一组指标的最终总和或截图相似替代数值断言。

每个断言点记录计算起点以来的完整输入，旧末根使用本轮最终修正后的值；新建
原生实例全部重放，逐时刻读取角色结果。正常裁剪不改变起点，参考保留测试期
全部输入并只在比较展示窗口时裁剪。异常重载重置全部起点；新增或改参数只重置
对应实例起点，其他实例继续与原起点对齐。

严格比较时间、输出角色、点数、预热／无值状态和每个数值，使用 Object.is 或等价
严格断言。warmup、value、合法 undefined、null、缺点和零不能混淆；CCI 原始 NaN
及正负零不因序列化丢失比较信息，不以 NaN 转为 null 的比较掩盖差异。
禁止 epsilon、toBeCloseTo、固定小数位、取整、重新平滑或人为修正结果。

组合指标覆盖 MACD 的 macd／signal／histogram 和布林带三轨，而非只测主输出。
正常增量对齐是本项目原生状态管理的硬条件，不将测试改为每轮重算来规避 replace。
仅输入过一根时采用上游写定的新实例 add 生命周期；展示容量为一不触发此例外。
任何差异输出指标、参数、计算起点、具体时间／角色、期望与实际及此前操作序列。

### 库可靠性与 fixture 来源

固定期望、全部合法边界、首根修正、常量 CCI 与 ADX 平滑恢复的准入职责在计算
spec，本阶段复用并复核其完整 fixture。来源、版本、参数与读取口径必须与正式
依赖相同，不能更新依赖而只替换期望，不把同库一致误报为独立可靠性。
浏览器与构建新增的集成样本继续离线，不编写参考公式或旧 pandas 生成器。
确认仅单指标存在库缺陷时，可暂不支持其 market 计算，保留原因和明确最小复现
断言；验收其拒绝行为及 legacy 展示。公共链路、默认 EMA、已开放指标回归或
重大设计问题仍阻断交付，不能删样本、加容差或静默改版本。

### 浏览器与两个入口

扩展现有离线浏览器 fixture，使用实际构建产物与本地行情 mock。参考可在测试
运行环境直接使用原生实例；浏览器侧使用实际应用计算结果进行严格比较，不把
测试预期直接注入应用当作计算成功。对原生结果的序列化必须保留角色及无值信息。

覆盖 market 全量初始化、末根替换、批量追加、连续裁剪和异常完整重载的真实
事件到图表链路；核实重载失败仍展示上一已提交快照，旧代次不会回写。
浏览器控制台 WARN 的身份、原因与差异字段正确，纯显示操作不取数、不重播。
CCI undefined 不发起请求，旧有限末点确实变成缺口；计算错误与取数失败分开，
前者停止自动更新而非反复完整请求。MACD 三角色首点使用根可用状态。

同一固定数值分别通过 market 结果和 legacy 导入列生成显示，比较相同参数／角色
的通用描述、Pane、轴、格式、颜色与参考线。legacy 值本身不强制改播种或重算。
显式样式与 Pane／索引覆盖使用真实文件配置，避免只测一个空适配器或 mock 返回。
无注记 legacy、底部栏、普通文件系列、箭头／风险线及 Notebook 导出继续可用。
两组相同参数、相同 output 使用不同 id 和不同导入值，确认系列不会被合并覆盖。
显式 RSI hline 被索引隐藏后默认线不会补回，referenceFor 精准关联及 Pane 级覆盖
生效；固定 Histogram 颜色消除自动点颜色，移除后恢复元数据策略。
market 标签没有显隐操作，删除／重加配置确实释放／重建实例及独占副图；
预热与合法 undefined 不删 Pane，legacy 原有配置显隐不扩展为 market 新功能。

### 最终退出与有效规范

检查生产源码、类型、测试、fixture、有效规范与使用说明：没有自研 EMA／其他
指标计算、最近五根计算检查点、旧 emas 状态／事件、旧参考生成入口、EMA 类型
门卫及失去调用方的桥接。普通字段比较缓存与通用 historicalUpdate 不属于残留。

共享图表和入口不根据指标名称、标签或列名决定显示；显示知识只存在于指标
定义与展示职责。普通文件映射、风险／仓位实现保留独立职责，不因清理指标删除。
逐个核对默认值、公开示例与生成声明，current spec 只描述当前实现，不与任务
阶段安排混写。保留历史 task 文档，不新增执行总结、审阅记录或手工索引。

## 公开接口与用户写法

不新增公开入口，只验收主任务与前置已冻结的契约。候选语法如下；实际提交只
开放通过逐项准入的类型，不支持项明确拒绝。legacy 元数据保留全部候选：

```toml
[dashboard]
indicators = ["sma,20", "ema,14", "dema,20", "tema,20", "rsi,14", "cci,20", "macd,12,26,9", "atr,14", "adx,14", "er,10", "bbands,20,2"]
```

```text
/?indicators=ema%2C14%3Brsi%2C14%3Bmacd%2C12%2C26%2C9
/?indicators=none
```

market 同配置重复、未知类型、缺参数、macd,26,12,9、bbands,20,0 与未知 legacy output
必须在约定阶段明确失败。错误不能被默认值、夹值、删项或旧解析回退隐藏。
legacy 的真实注记 JSON 见显示 spec；用该写法验证普通配置与显式覆盖，不发明
额外配置版本或替代注记协议。Just 命令、后端 API 与 hash 自选仍保持原契约。
legacy 不同 id 的相同参数／角色合法；同 id 角色重复及非法 referenceFor 失败。

## 测试、验证与阶段过渡

实施使用正式 `just check`、`just test`、
`just market --build`；默认离线测试不得访问外部行情或真实账户。
`just test` 的正式浏览器 fixture 承接 market 与 legacy ES／UMD 构建及临时复制，
不以手拆底层命令或新增在线测试替代。不得写入真实 Notebook 目录。

在前置严格测试基础上补齐以下验收范围：

- 所有十一指标及复合角色的固定小数输入、固定 seed 序列、反复末根覆盖后多根
  追加、持续裁剪、重复批次、起点变更与完整重载，严格相等且预热状态一致。
- 复核计算阶段已通过的每种指标固定结果及边界可靠性 fixture；来源可核对，不把同库对齐误报为
  独立证明，不保留自研参考公式。差异信息足以离线复现，失败不会被跳过。
- 缺末根但有历史重叠、历史字段不同、窗口不足五、合法时间跳空、重载失败、
  取消及旧代次晚到的真实请求数量和提交行为，不能只断言某次抛了任意错误。
- Bun 与实际浏览器计算链路使用同一锁定依赖，传递原始输出不改变数值；实际
  ChartController／registry／图例收到正确结果，而非只验证 mocked patch。
- 真实 SDK 的缺口时间线、断线与状态图例回归沿显示 spec 执行；MarketHub 在新增
  指标初始化失败时仅暂停失败周期，其余周期采用新配置继续更新。移除失败配置后
  保留原流身份，恢复正确配置和增量更新；在途旧响应不能覆盖错误快照。
- 两入口元数据复用、全部类型的副图／多输出、显式覆盖、参考线释放、主题、
  格式、Pane 与视窗，同参文件组身份、隐藏显式线及固定柱色优先级；设置应用／
  取消／前进后退和 query／hash 保持一致，market 不新增组显隐参数。
- 生产／测试遗留退出、类型与构建声明、有效规范和使用说明，既有部署配置和
  无后端独立启动的离线回归不受新依赖影响；不要求实际生产或远程部署。
- 集成版本继承前置的实际设置 Pane 协调、Notebook 独立轴及导入缺口回归；
  正式库构建和递归复制包含声明，消费验证只读取临时目标声明与已安装依赖，
  不以源文件补齐产物缺失；ES／UMD 合法写法及错误类型拒绝均通过。

检查正式验证中的 warning、deprecation、异常跳过与 summary；没有解释的警告
不能报为干净通过，第三方问题按主任务停止线处理，不事后修改规范增加豁免。
本阶段完成后无需另建主任务验收 change，不重复已覆盖的验证或无限扩大清理。
