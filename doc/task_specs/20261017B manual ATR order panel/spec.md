# 手动 ATR 风险下单面板

## 任务边界

为 `just market` 的按钮栏增加“下单”入口及浮层。内部使用模式 Tab，首版唯一
模式为“固定风险金额＋ATR”，完成双向预览、一次市价入场、成交核实、并发提交
止损／止盈市价触发单及结果展示。开发中间件与生产 Bun 服务使用同一业务链。
同一任务包括看盘设置恢复默认值、外部关闭及自选编辑的清空草稿操作。

正式规范由本文件及以下扩展共同构成：

- [spec_01_backend.md](spec_01_backend.md)：后端实际路由、schema、适配规则和现有缺口。
- [spec_02_calculation.md](spec_02_calculation.md)：报价、ATR 复用、含费计算、网格及容差。
- [spec_03_execution.md](spec_03_execution.md)：一次执行、HTTP 契约、核实及部分失败。

本任务在同一 JJ 内实现代码、离线测试和受影响的 current spec／guide，不修改
ccxt-proxy2 仓库、真实账户配置或部署。后端部分以当前实际
OpenAPI 路由及实现为准，未提供的事实明确记为限制，不定义占位的成功响应。

首版功能边界：

- Binance／Kraken 的 `market=future` 且 `swap=true、linear=true` 的可交易品种。
  报价币与风险结算口径须一致；不处理反向、交割、现货及跨币损益换算。
  费率对接范围为 Binance 实盘／模拟盘、Kraken 实盘；Kraken 模拟盘因账户费率
  路由不支持而禁用交易。实际市场、规则与模式准入见后端扩展。
- 所有来源均有面板入口；TQ 显示“待实现”。CCXT 不支持的市场显示具体原因，
  不把现货符号偷偷改为永续，也不把未启用的 sandbox 切到 live。
- 首版使用单向模式写法；已确认双向模式禁用，模式无法确认时显示提示后允许
  提交，由交易所拒绝不兼容请求。不自动切换账户模式，也不新增资金预检。
- 仅市价入场；首版不显示一个可选择却无法正确执行的限价选项。Tab 用于下单
  策略模式，未来增加限价并不等于必须另建策略 Tab。
- 不做余额、可用保证金和杠杆预检；资金不足由实际入场拒单反馈。
- 不做自动写重试、补单、平仓、撤销另一保护单、持久化交易任务或重启恢复。
  已提交保护单由交易所保存，用户自行管理剩余挂单；两单不是 OCO。

保留现有看盘设置、URL、hash、自选、绘图、指标算法、legacy／Notebook 和部署
入口。交易参数不进入 TOML、URL 或浏览器持久化存储，不改变图表身份；仅面板
布局和宽度进入既有公共设置链。

停止线：支持范围内两家交易所均可按同一前端写法完成正常流程；非法输入、不可
计算、拒单、部分成交、单腿失败和未知结果均符合明确语义；离线逻辑、真实浏览器、
开发／生产 HTTP 适配及原有回归通过。真实后端能力缺失阻断对接验收，不能以
fixture 成功替代；不为了交付扩大到后台交易管理系统。
未知上下限、名义金额依据和模式证据按后端扩展给出警告，不阻断手动提交。
计算必需事实缺失、已知规则不满足或容差无解仍阻断，不能把允许尝试写成成交保证。

## 任务规范

### 界面与默认值

新增按钮为按钮栏固定区域中的 32×30px 按钮，顺序为设置、下单、列表入口、
滚动平铺品种列表，支持四种栏方向和深浅主题。悬浮使用既有定位；平铺实际占位，
图表复用实例并通过 resize 适配。关闭按钮、Esc、再次点击下单按钮直接关闭，不再
确认或丢弃草稿。悬浮在外部点击、打开其他浮层及切品种时收起；平铺在这些操作时
保持显示，可与设置／自选浮层共存。浮层位于平铺面板上方，有浮层打开时 Esc 不
连带关闭下单面板。打开下单面板仍关闭设置／自选浮层，
关闭下单面板不改变图表、自选或已经发起的一轮执行。

面板第一层清楚显示来源、交易所、实盘／模拟盘和品种；内部一枚已选中的模式
Tab“固定风险金额＋ATR”。交易所和环境随图表身份并只读
展示，不能由 symbol 字符串推断或切换；品种及周期可独立编辑。

仅首次打开初始化默认参数。页面持有唯一一份已确认参数、原始文本草稿、待确认
标记、编辑错误、参考方向 Tab、示例线显示选项和三个区域的展开状态；各品种共用，不按品种建立缓存。关闭或切换
显示形式不清空，包括空输入、半输入和非法值。已发起执行及最近结果继续由页面
持有。不同 tab 独立，整页刷新及关闭 tab 清空；不用任何浏览器存储或后台保存。

| 字段 | 首次／重置默认值 | 编辑与约束 |
| --- | --- | --- |
| 品种 | 当前图表完整 canonical symbol | 可编辑；最终以市场资料返回的身份核对 |
| K 线周期 | 当前全部窗口按时长取最小周期 | 可编辑；使用现有 TIMEFRAMES，后端不支持时明确报错 |
| ATR 根数 | 14 | 可编辑，整数 1..10000；复用指标参数校验及行情容量边界 |
| 风险金额 | 1 | 有限正数；币种取市场 quote，只读，不把 USD 当作 USDT |
| 止损 ATR 倍数 | 2 | 有限正数 |
| 金额容差 | 5% | 可编辑，0% ≤ 值 < 100%；金额指含费总风险 |
| ATR 倍数容差 | 5% | 可编辑，0% ≤ 值 < 100% |
| 止盈倍数 | 2 | 有限正数，表示止盈价格距离／止损价格距离 |
| 入场方式 | 市价 | 首版固定 |

周期按秒数比较，不取数组首项或按字符串排序。图表完整身份变化时，无论来自
自选、设置或 URL 导航，悬浮收起，平铺保留，并更新记忆中的来源、交易所、市场、环境
以及草稿／已确认值中的 symbol；保留两份数值参数、周期和待确认标记。取消
恢复上次确认的交易参数，但不回退新品种。普通关闭重开不覆盖手动输入的品种。
平铺切换身份立即释放旧读取与 ATR 需求，清除示例并加载新身份的已确认参数，旧
响应不得覆盖新资料；新资料未就绪前不能下单。切 TQ 保留面板并停止读取，显示
待实现；切回 CCXT 恢复读取。悬浮关闭后在重开时读取。待确认标记及草稿保持，
已发起执行及日志保持原身份，不被导航或配置修改。
其他图表配置及只改布局／宽度的 URL 导航不清空交易草稿。
无法取得有效当前图表配置时显示原因，不能猜测实盘身份。

参数、参考、日志为三个独立可折叠区域，首次默认展开，以后恢复各自状态，折叠不卸载数据订阅或
执行结果。参数使用紧凑多列布局，默认 230px 保持两列，宽面板最多四列；数字及
周期输入框宽度至多 80px，不随面板拉长，品种框跨两列。保留完整标签及键盘操作，
仅在可用内容宽度不超过 160px 时退为单列。
面板正文字号为 13px，参数和参考数值为 12px，辅助说明为 11px。

六个数值参数使用同一个紧凑微调输入组件，80px 宽度内右侧内嵌上下箭头；单击与
键盘上下键每次按原值加／减 1，容差为一个百分点。复用精确十进制运算，保留小数，
如 1.5 加 1 得 2.5。仅输入框有焦点且鼠标在框内的纵向滚轮生效，上滚加 1、下滚
减 1，消费滚轮事件以免同时滚动面板；未聚焦、横向或带修饰键时保留默认行为。
原始文本绑定保持不变，空／非法半输入禁止微调、不替换为默认值。微调沿既有输入
链路标记草稿待确认，不钳制值域，不自动生效或触发请求；值域仍在确认时统一校验。
组件自管输入事件及清理，箭头、焦点和禁用样式适配明暗主题，键盘 Tab 仍逐输入框移动。

面板提供参数“确认”“取消”、“强制刷新”与“做多／做空”操作。任何参数输入
修改后进入待确认状态，即使手动改回原值，也须确认或取消。此时禁用下单、强制
刷新和结果查询；允许继续编辑、折叠及关闭，自动行情更新与已准入执行不受影响。
确认完整草稿校验成功后整体生效；失败保留待确认状态且不启动新请求。取消恢复
本页上次确认的交易参数并清除编辑错误，不请求新身份。无变化确认不重置
行情、指标或 ticker。没有待确认改动时确认与取消禁用。

“重置默认值”只将当前图表品种、最小周期及表中数值填入草稿，标记待确认；
确认后生效，取消恢复已确认参数，不重置布局、宽度、折叠或交易结果。

面板标题提供悬浮／平铺切换，公共设置包括 order_panel_layout、order_panel_inline_width、
order_panel_floating_width。布局为 floating／inline，默认 floating；两项宽度分别用于
平铺及悬浮，均为正的安全整数像素，默认 230。切换布局不覆盖另一项宽度。
TOML 缺省、runtime、URL 与设置采用同一校验，不接受非法值或重复 URL 字段。
旧 order_panel_width 字段退出，代码、配置模板、URL、类型及消费者统一替换，
不保留兼容别名；旧 URL／TOML 须将原值分别填入两项新字段。完整 query 基础字段为 18 项。
切换按钮只应用显示设置并更新 URL，不提交交易草稿，不重建面板或行情订阅。
平铺在右栏时为图表、面板、按钮栏；左栏镜像，上下栏时面板仍位于图表右侧。
关闭后不占空间；实际宽度受可用空间限制，平铺至少为图表留下 min(160px,40%)，
不改写 URL 中的设定值。两种显示形式共用自适应紧凑布局。

看盘设置“恢复默认值”重填本次服务 runtime.defaults 的全部设置草稿、公共及窗口
指标文本，清除错误；不立刻修改图表、URL、TOML 或自选，应用后生效。取消、关闭、
Esc 及点击面板／设置按钮以外区域丢弃设置草稿；按原始事件路径识别内部点击，
切 Tab 不误关闭，平铺下单面板不连带收起。自选编辑“清空全部”只清空列表草稿、
错误及拖拽状态，空列表禁用；保存后更新 hash，保留 flat 与当前图表，取消不提交。

强制刷新按钮旁持续显示距当前生效品种最近一次 ticker 成功响应的整秒数；首次
成功前显示尚未成功刷新，失败不重置计龄，换品种清空旧计龄。按钮每次接受点击
后冷却 5 秒，冷却或本次刷新未完成时禁用；状态层同时拦截重复调用，不排队。
冷却不因自动 ticker 成功而延长，不限制每秒自动刷新。只刷新生效身份的规则／
费率／模式证据、ticker 和既有单飞行情；与在途 ticker 共用请求，不提交草稿、
不重新播种未变的 ATR，也不续做过去的交易流程。

TQ 及其他未实现来源展示“待实现”和关闭入口，不发起本面板的 ticker、K 线、
市场资料或手续费请求；现有看盘请求照常。CCXT 范围外品种禁止交易并说明原因。
TQ 占位不展示旧 CCXT 结果，但不删除页面持有的结果；再次打开 CCXT 面板时，
结果区须带原交易身份，不能与当前草稿混为一笔。

### 预览及资源生命周期

打开有效 CCXT 面板立即加载市场规则／费率／模式证据、ticker 和所需 ATR；各项准备完成
前显示对应状态，不能把旧品种结果当新预览。做多／做空参考使用两个 Tab，首次
默认做多，同页记住选中方向；支持点击及左右方向键、Home／End 切换，每次只显示
当前方向。两方向持续计算，不因切换 Tab 增加读取或重建订阅。公共区域显示 ATR；
各方向按以下顺序展示：参考入场及来源、合约数量、基础币数量、仓位名义价值、价格风险、开仓／
止损费用、金额／ATR 误差、止损／止盈、实际 ATR／止盈倍数、预计含费风险、预计
止盈净收益；不可计算时显示具体原因。净收益不承诺等于风险金额乘以价格倍数。
未知额度约束和模式证据作为警告与预览一起展示；计算资料缺失或环境不支持时
明确禁用。费用展示账户费率来源和后端 updated_at。

ticker 每 1000ms 调度一次，同一生效身份最多一个在途请求；上一请求未结束时
跳过本次节拍，不排队补发。成功或失败结束后等待正常下一节拍，不做紧密重试。
关闭、卸载或应用新身份时清理 timer、取消面板只读请求并丢弃旧代次响应。
更改风险金额、倍数或容差只重新计算，不重新创建 ticker timer 或重取历史。

报价、ATR 的可用性、缓存、共享及过期规则只在
[spec_02_calculation.md](spec_02_calculation.md) 定义。市场规则、费率和模式证据在打开、
换品种及用户显式刷新时加载，不跟随一秒 ticker 反复取全量资料。
lwchart 统一适配实际的 fetch_market_info、fetch_trading_fee、fetch_positions 三个
读取入口；每次提交服务端重新读取并核对，仍不读取余额作资金预检。

点击做多／做空按钮先弹出确认，显示交易所、品种、实盘／模拟盘、方向及当前参考
数量、价格、仓位名义价值、含费风险及预计止盈净收益；金额带对应币种，使用同一预览结果并随
报价更新，此时不发送交易请求。取消或 Esc 只关闭确认框并保留下单
面板；未确认的弹窗不跨面板关闭或交易身份变化保留。确认期间继续刷新预览，资料
失效时禁用确认；最终确认按最新有效数据重新校验，再冻结本次请求。参数待确认
或打开其他设置浮层时取消尚未提交的确认，双击确认也只能发起一轮。

参考区提供“查询持仓”，仅点击后按下单完整身份独立读取一次持仓，不复用早先的
模式证据。打开面板／确认框、ticker 和强制刷新不触发此展示查询。确认框不显示
持仓信息，不等待查询完成。查询单飞，参数待确认及交易／结果查询中禁用按钮。
返回后醒目显示空仓／已有仓位／未能确认，列出非零或未知记录的方向、合约数量、
持仓均价、品种与查询时间；双向记录分别展示，不净额抵销。空列表或全部明确为零
才显示空仓，未知数量不能当作零。已有仓位提示可能增加、合并或抵销；失败及信息
不完整仅提示，不影响下单确认。关闭面板或切身份取消请求、清空快照并隔离迟到
响应；重开／换品种须重新点击。服务端读取不超过 8 秒，浏览器不超过 10 秒，
不自动重发。既有模式证据及执行后核对继续独立运行；HTTP 形状见执行扩展。

一次确认提交冻结方向、身份、参数、报价和 ATR 快照。后续 ticker／K 线变化或草稿
编辑不得改变已经发出的数量或那一轮参数。页面内执行单飞，进行中禁用两侧
提交按钮；显示入场、止损、止盈各自进展，不能只用一个“成功／失败”代替事实。

参考、确认、日志统一使用“仓位名义价值”“预计含费风险”“预计止盈净收益”及
对应报价币。名义价值使用既有计划的数量、精确乘数及入场价派生，复用同一精确
计算入口；公式和量纲见计算扩展，不新增后端字段。价格风险及费用同样标注币种。
日志显示“本轮成交估算（提交时）”，使用 submitted_plan 中实际成交数量及均价；
部分成交只计已成交部分，收益沿用该计划的开仓费用来源。后续行情、参数、品种
变化和只读查询均不重算这份快照。没有 submitted_plan 时提示暂无可用成交估算，
不使用当前预览、账户总仓位或零值代替；保护失败仍保留原估算并单独报告每腿状态。

### 调用及所有权

当前参考 Tab 使用横向拆分控件：主按钮未开启时为“画线示例”，开启后原位变为
“取消示例”；右侧按钮展开多选菜单，包含止盈线、止损线、仓位线显示，首次全选。
仓位线指本次参考入场线，与确认框查询到的账户仓位分开。勾选即时过滤示例线及
对应标签，不改变计算、下单参数、编辑标记或请求节拍；隐藏线退出自动纵轴并集。
全部未选时隐藏全部线；已开启的示例状态保留，未开启时主按钮禁用。选项随当前
页面记忆，关闭／切品种／重置交易参数保留，新页面恢复全选，不进入 URL 或存储。
菜单内部多选保持展开，外部点击收起；菜单聚焦时 Esc 只收起菜单。
切换参考 Tab 清除旧方向示例，新方向须显式开启。示例暂时隐藏时仍可取消。
示例使用对应已确认预览中完成精度处理的入场／止损／止盈价格，所有当前品种的
主图显示同一组值，不按各图周期重算 ATR。图表与下单完整身份必须一致；参数待
确认、数据失效或执行中不能开启示例。编辑和短暂数据失效时隐藏；取消示例、
关闭窗口、任一侧切换身份或点击下单时结束示例，后续成功报价不会自动重新开启。
时间轴位置保持；示例价格纳入自动纵轴范围，清除后恢复原范围计算，手动纵轴不强制解锁。
示例使用 labelPosition="left"，图内左侧只显示“多入／多损／多盈”或对应“空”标签
及格式化价格，右侧不重复显示；面板仍显示正在示例。左标签以官方 series primitive
绘制，每系列最多一个，随 SDK 重绘取坐标。相近标签只做显示避让并以短引线对应
真实价位，不改变线价或时间视口。标签、更新及销毁均归共享图表模块，不增加业务层绘图逻辑。

价格线实例、差异更新、移除、缩放及系列销毁清理全部归共享图表模块所有。
ChartApi 与 LWChart 暴露 setPriceLineGroup／clearPriceLineGroup；市场模块只传配置。
每组按 series 与 id 隔离，组内每条线按 id 复用；未变化不更新，变化调用官方
IPriceLine.applyOptions，不能每秒重建线或重放 K 线。现有配置参考线继续有效，
清除示例不得删除 RSI 等指标参考线。不增加定时器、行情请求或持久化状态。

浏览器复用既有 MarketHub／MarketStream／CandleStore／IndicatorStream 取得 ATR。
新增含费风险与价格／数量网格计算模块由浏览器预览和 Bun 提交校验共用。
该模块只消费数值及归一规则，不引入绘图库或重新实现 ATR；生产服务继续遵守
现有构建依赖边界，不加载 trading-signals。

一次短流程由 lwchart 的 Bun／Vite 共用 API 执行。ccxt-proxy2 仍只接收单笔读写
请求；后端不需要提供括号订单、原子事务、执行队列或资金预检。
入场先提交并核实，再并发发送止损与止盈，随后进行一轮只读核实；详见
[spec_03_execution.md](spec_03_execution.md)。

关闭浮层只停止预览请求，不取消已经准入的执行。完整请求准入后，执行使用自身
超时而非页面 AbortSignal；服务进程仍存活时，即使页面断开也完成这一轮有限流程。
服务重启、结果响应丢失或浏览器刷新后的恢复由用户查交易所处理，不提供恢复保证。

### 校验及失败语义

前端先校验完整草稿、行情可用性、规则及误差，服务端在任何交易写请求前再执行
同一输入与计算校验。缺报价、ATR 未预热／异常、价格／数量网格缺失、费用未知、品种身份
不匹配、非支持市场、精度不合法或无可行数量均禁用提交并给出原因，不默默补值。

资金不足等明确拒单只展示错误；网络超时或事实不足显示“状态未知”。写操作不
重发，查询结果也不能隐含补挂、平仓或再次入场。部分成交按可确认的实际数量
处理；提交前容差阻止入场，成交后偏差不触发自动调仓，详见计算和执行扩展。

账户中的原有同品种仓位不等于本次成交。结果分别展示本次订单和账户持仓；
保护单使用本次成交数量及只减仓语义，不承诺旧仓与本次订单独立。与已有净仓
冲突时保留交易所真实结果，不自动改方向、数量或整仓平仓。

## 公开接口与用户写法

已有启动、构建、部署命令与品种参数写法保留；URL 使用三个面板显示字段。默认用户流程：

1. 当前图表为 `BTC/USDT:USDT`，周期为 `4h、30m、1d、1w`。
2. 点击“下单”，初始品种为该 symbol，周期为 `30m`，ATR14、风险金额 1 USDT、
   止损 2 ATR、止盈 2 倍，两项容差均为 5%。用户可改品种／周期并点击“确认”，
   或点击“取消”恢复已确认参数；未处理改动前不能下单、强制刷新或查询结果。
3. 在做多／做空 Tab 中预览结果；点击所选方向的市价下单按钮，再点“确认做多”
   或“确认做空”才执行一轮交易。“取消下单”或 Esc 不产生交易。关闭面板停止 ticker 轮询。

显示配置示例（其余参数仍遵守现有 URL 补全规则）：

```text
http://127.0.0.1:5174/?order_panel_layout=inline&order_panel_inline_width=230&order_panel_floating_width=480
```

风险金额 1 已确认，草稿改成 2 后切到 ETH：面板关闭，再打开显示 ETH、2、待确认；
点取消恢复 ETH、1。布局／宽度可随 URL 前后退恢复，交易草稿不会随显示设置回退。

以下是纯计算样本，不是可通过现有后端全部预检的交易承诺：参考价 10000，ATR100，
合约乘数 1，数量步长 0.0001，价格步长 0.1，开平 taker 费率均为 0.001。
风险预算 1、止损 2 ATR、止盈 1 倍、两项容差 5%，多单得到数量 0.0045、
止损 9800、止盈 10200、价格亏损 0.9、预计费用 0.0891、含费风险 0.9891。

```text
做多参考：数量 0.0045 BTC；止损 9800；止盈 10200
含费风险：0.9891 USDT；金额误差 1.09%；ATR 倍数 2
预计止盈净收益：0.8091 USDT
```

关键反例：数量／价格网格无法同时满足两项容差时，没有下单请求；预算 0、容差
100%、ATR 根数非整数、未知品种和缺失费率均不能提交。拒单不发送保护单；
“入场已成交、止损失败、止盈已挂”必须按三个独立结果展示。

本任务的 lwchart HTTP 入口如下，与 ccxt-proxy2 单笔路由明确分开：

| 方法与路径 | 用途 |
| --- | --- |
| GET `/api/ccxt/fetch_market_info` | lwchart 聚合已有市场规则、账户费率及持仓模式证据，保留实际字段语义 |
| GET `/api/ccxt/fetch_ticker` | 提供面板报价及本地获取时间 |
| GET `/api/ccxt/fetch_positions` | 面板按钮手动读取当前品种持仓，与执行后核对共用归一规则 |
| POST `/api/ccxt/manual-order` | 执行一次已选择方向的市价入场及保护流程 |
| POST `/api/ccxt/manual-order/check` | 用户显式只读核实已知订单，不触发交易 |

K 线继续使用现有 `/api/ccxt/fetch_ohlcv/latest-limit`；不新增 ATR 后端 API。
输入输出完整定义与可执行 HTTP 示例见
[spec_03_execution.md](spec_03_execution.md)。实际后端接口的字段集中在
[spec_01_backend.md](spec_01_backend.md)，不能混同两层 API。

图表分组价格线公开写法；空 lines 等价于清除该组，未知系列、空组／线 ID、
重复线 ID 或非有限价格在任何绘图修改前报错；颜色、标题为字符串，样式和线宽
采用 SDK 的有效枚举值。相同系列其他组互不影响，静态重建不自动恢复临时组。

```ts
chartApi.setPriceLineGroup({ series: 'candles', id: 'order-preview', autoscale: true, labelPosition: 'left',
  lines: [
    { id: 'entry', price: 10000, color: '#3b82f6', title: '多入' },
    { id: 'stop', price: 9800, color: '#ef4444', title: '多损' },
    { id: 'take-profit', price: 10200, color: '#10b981', title: '多盈' },
  ] });
chartApi.clearPriceLineGroup('candles', 'order-preview');
```

labelPosition 仅允许 axis／left，缺省 axis 保持原生标签；left 在绘图区左侧显示标题
及本系列 priceFormatter 格式化的价格，关闭原生标题与轴标签。axisLabelVisible=false
在两种位置均隐藏标签。非法位置整组拒绝；切回 axis、清组及系列销毁释放左标签。
