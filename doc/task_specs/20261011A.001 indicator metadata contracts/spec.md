# 指标元数据与参数契约

## 任务边界

建立十一种指标的共享定义、规范化参数、实例身份与显示描述，迁移现有 EMA 的
参数解析、序列化、标签和默认配色调用。后续计算与显示扩展以此为唯一来源。
最终参数、输出角色与显示规则见 [主任务 spec](<../20261011A unified technical indicators/spec.md>)
的“指标定义与参数”“显示元数据与双入口”，本任务不另设一份取值表。
原生构造、输入、读取 API、角色与可用状态的唯一对应表在
[spec_01_native_contract.md](spec_01_native_contract.md)，与本 spec 一起必读。

计划新增内容位于 src/indicators/；相关 current spec 在本阶段实现后同步真实有效
的定义与过渡范围。doc/current_specs/indicators.md 是计划产物，不是已有规范。
复用 src/crypto/options.ts、query.ts、data/chartData.ts 和既有配置加载入口。
共享显示类型归共享模块所有，不反向导入 legacy 的文件路径与页面配置类型。

本阶段不安装 trading-signals，不修改 EMA 数学过程或行情合并规则，不增加副图、
复合输出绘图和 legacy 新注记的用户功能。公开 market 暂时保持 EMA 子集；已有
EMA 配置、none、三个默认 EMA、query／hash、主题、时区、布局继续可用。

停止线：参数与显示定义只有一个真值源；现有 EMA 的实际调用使用新定义；全部
十一种指标的定义完整并可离线核对；公开入口不能接收尚未完成显示的类型。
缺字段、解析副本、同配置身份不稳定或破坏现有入口阻断本阶段交付。

## 任务规范

### 定义与职责

使用严格 type 联合表达指标种类及对应参数，不能用任意字符串加宽松参数对象
掩盖配置错误。定义包含参数字段与默认值、输入依赖、原生库构造配方、输出角色
与结果映射、可用状态，以及主任务规定的完整显示元数据。

库构造配方和读取口径以扩展表冻结，本阶段核对发行源码，计算阶段仅绑定执行。
候选与合格版本选择遵守主任务，不能由适配层或测试分别选择 EMA／DEMA、平滑器
及子指标预热。不得提供自写计算、返回假值的计算器或运行时
抛错占位函数，不能在两个入口中各自保存一张指标类型表。

计算状态、行情窗口和图表实例不进入不可变定义。主题配色以角色表达，解析
明亮／黑暗颜色不依赖当前行情。参数影响的名称从实例参数生成；显示文本不能
作为状态或系列的唯一键。market 配置键与 legacy 文件组 id 是两种入口身份，
按主任务格式生成系列键；同参数、不同 legacy id 的系列不能互相覆盖。

定义声明 Line／Histogram 等通用原语、轴／缩放贡献、主图或独立 Pane、参考线、
数值格式、配色角色、柱色策略、图例／显隐、组内顺序及 Pane 权重。均线、布林带
与副图的不同规则属于定义，不转交给图表按指标名称补全。
ADX 不隐式添加 DI±，布林带不声明尚未支持的填充效果。

### 参数与校验唯一来源

规范化对象、紧凑字符串、列表校验与序列化使用同一组定义。严格执行主任务的
字段、边界与参数个数。十二实例与同配置去重只作用于 market 列表；legacy 每项
校验单个 spec，按 id 聚合角色，不把多角色项或不同文件组当成重复计算配置。
配置文件、URL、设置草稿及未来计算适配均调用它，旧 EMA 专用校验与序列化退出。

保留现有错误定位方式；不把非法配置悄悄改成默认值。字符串缺参数、未知类型、
非法数字、额外字段及重复项在调用取数或计算前失败。数字序列化确定且可往返；
配置等价时规范化配置键相同，不同 type 或参数时不同；入口身份再决定实例／组键。

共享解析能够表达十一种类型。公开 market 在本阶段另做明确的可用范围检查，
仅允许 EMA；这项临时限制复用同一解析结果，不建立第二个 EMA 解析器。
拒绝其他类型时说明当前阶段尚未支持，不能尝试取数、自动删项或装作配置成功。

### 现有调用迁移

现有 EMA 的名称、颜色、输出角色和默认主图显示读取共享定义。设置与 TOML／query
复用共享参数契约，三个默认 EMA 的数值与视觉行为保持现状。
将共享样式描述从 legacy 页面类型中抽离，页面配置通过适配传入通用描述。
不要在本阶段扩大迁移到与指标无关的箭头、风险线或文件格式。

允许暂时保留 market 调用方的 EMA 类型收窄，及现有计算结果到共享显示描述的
无计算适配；必须标明调用方和移除条件。它们不能复制参数规则或任何指标公式。
旧 EmaSeries 在本阶段仍是唯一计算实现，由后续计算阶段整体替换。

## 公开接口与用户写法

本阶段保持已有 market 写法，默认配置与下列示例均可用：

```toml
[dashboard]
indicators = ["ema,14", "ema,50", "ema,100"]
```

```text
/?indicators=ema%2C14%3Bema%2C50
/?indicators=none
```

最终通用写法及 legacy 注记已在主任务“公开接口与用户写法”冻结；本阶段尚不
开放 rsi,14 等非 EMA 的 market 配置，也不宣称 legacy 注记已经生效。
ema,0、ema,14;ema,14 和缺参数 ema 均明确失败，不能沿用旧的静默修正行为。

共享参数模块内部使用的规范化对象示例：

```ts
{ type: 'ema', period: 14 }
{ type: 'macd', fast: 12, slow: 26, signal: 9 }
{ type: 'bbands', period: 20, deviation: 2 }
```

这些对象表达已确定的契约，不新增公共计算 SDK 或运行时注册接口。

## 测试、验证与阶段过渡

实施使用仓库正式 `just check` 与
`just test`，全部默认离线；不得手拆内部命令代替正式验证或新增在线测试。

离线测试证明：

- 十一种定义各有完整参数、输出和显示元数据，未知 type 不会进入图表猜测分支。
- 合法规范化对象与字符串往返一致；空列表、边界周期、MACD 参数顺序、布林带
  deviation、未知字段、缺／多参数及十二实例上限遵守主任务契约。
- 相同配置重复失败；不同类型同周期和同类型不同参数合法，实例及角色键稳定。
- 两个 legacy 文件组的相同参数／角色具有不同键，同组角色必须唯一；参数校验
  共用，market 列表去重不越过入口边界。
- 扩展对应表覆盖全部原生构造、输入字段、读取及可用状态，MACD 三角色采用整体
  可用判定；CCI 合法未定义与其他非有限错误明确区分，不在图表补结果判断。
- EMA 标签、主题配色、图例与默认主图描述来自元数据，设置／URL／TOML 没有副本。
- market 临时可用范围拒绝非 EMA 且不发起请求，已有 EMA、none、应用／取消与
  URL 前进后退、既有图表及 legacy 回归通过。

本阶段不验证库的数学结果，不把元数据完整误报为指标计算已可用。
计算阶段逐指标准入，单指标不通过时可暂不开放 market 计算，仍保留元数据与
legacy 展示；本阶段的定义不能将候选状态当作实际计算已通过。
后续计算阶段删除旧计算并绑定原生库，继续保留公开 EMA 范围以保障入口可用；
后续显示阶段启用全部类型与 legacy 注记，同时删除临时范围检查、类型收窄及
已经失去调用方的数据适配。每阶段必须可用，不接受预先约定之外的测试失败。
