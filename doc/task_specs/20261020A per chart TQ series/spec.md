# TQ 逐窗口主连与加权

## 任务边界

交付 TQ 来源设置内的逐窗口形式选择、URL 往返、统一符号替换及相关离线验证。
同时调整下单面板持仓查询生命周期：实际下单身份变化时清空旧持仓与条件单清理显示。
保留原基础品种、周期、指标、自选、来源切换、图表实例和共享行情行为。
同步受影响 current spec 与 guide；不修改后端、TQ 下单、公共图表绘制或旧 Notebook。
不新增主连映射查询、合约推导、浏览器存储、后台轮询或 TOML 配置项。
达到设置可用、精确替换、具体合约忽略、身份隔离与既有入口回归通过即可交付。
错误 URL 静默通过、改写具体合约或把主连与加权共用为同一行情流均阻断交付。

## 任务规范

### 配置与生命周期

TQ 品种框下按当前布局的位置编号与周期列出每个窗口，选择跟随品种／主连／加权。
默认跟随；选择仅改草稿，统一应用或取消。具体合约时仍保留选择，提示“当前为具体
合约，此设置不生效”。设置恢复默认值时回到全部跟随，应用后才改变实际行情。

页面内部用 chart_tq_series 稀疏映射，键为当前布局内的一基窗口位置，值仅为
main／index；缺键表示跟随。每次归一产生独立映射，不改变输入对象。缺字段兼容
为空映射，null、数组、非法编号、超出布局或非法值明确拒绝。非活动来源也校验并
保留该配置，CCXT 行情身份与请求不消费它。TOML 不接受此字段，服务 runtime
默认提供空映射；页面改动不回写服务配置。

配置跟随位置，不跟随周期。菜单缩小布局保留前 N 项，扩大新增窗口默认跟随。
导航按完整 URL 恢复，手写 URL 显式越界时整体报错、不发行情请求。
自选切换只改变公共基础品种／来源，保留形式配置；切成具体合约时不删除配置。

### 符号与行情所有权

统一纯函数负责替换：没有覆盖时原样返回；只有开头严格匹配 KQ.m@ 或 KQ.i@
时才能转换。main 使用 KQ.m@，index 使用 KQ.i@；交易所及品种后缀完全保留，
不替换中间出现的 m@／i@，不规范化大小写、不裁剪文本、不补造合约代码。
没有上述前缀的品种（包括具体合约）始终原样返回。

MarketHub 创建每个 TQ 窗口行情身份时按窗口选择调用此函数。窗口的流、请求、
标题均使用解析后的实际 symbol；设置、自选、页面基础品种仍使用原始输入。
现有按来源、symbol、周期和容量共享的流继续作为唯一数据链路，同身份复用，
主连与加权身份不同则分流。单窗口切换只影响对应需求，仍被其他窗口使用的流
不能释放；最后一个需求移除时停止旧流，迟到响应不能污染新身份。
符号解析只发生在配置协调阶段，不增加每秒计算、映射请求或新的 timer。

### 下单身份切换后的查询显示

页面级执行状态统一处理身份变化，比较交易所、市场、实盘／模拟盘和完整 symbol；
离开 CCXT 同样清空。图表导航在面板关闭期间也更新此状态；面板手填品种确认后
同步实际下单身份。清空持仓快照、清理结果、查询错误，切回旧身份也不恢复。
同身份关闭重开保留清理结果；仅编辑未确认草稿、风险参数、周期或显示配置不清空。

纯查询在切身份时取消，并隔离迟到响应；已准入清理继续，保留在途标记及本页开仓／
查询互斥直到原流程结束。清空后不展示旧品种明细，仅提示上一品种清理仍在进行。
旧清理返回结果或错误均不重新显示；结果丢失仍等待原有限执行窗口结束后解锁。
不因切换自动发起新查询，不重试撤单，不改变交易参数、查询偏好和原三腿执行日志。

## 公开接口与用户写法

URL 新增 `chart.N.tq_series=main|index`；N 与现有窗口编号一致。省略参数表示
跟随品种，界面选择跟随时删除该参数，不提供 inherit 别名。显式同值选择仍保留，
例如输入主连且窗口选择主连，也保留 main，以便之后切换基础品种时维持选择。
序列化保留原十八项基础参数及指标覆盖，按窗口编号写入显式 TQ 形式。

```text
?source=tq&tq.symbol=KQ.m%40SHFE.rb&timeframes=30m,4h&chart.2.tq_series=index
```

此例窗口 1 请求 KQ.m@SHFE.rb，窗口 2 请求 KQ.i@SHFE.rb；各自标题显示实际品种。

| 基础品种 | 选择 | 实际品种 |
| --- | --- | --- |
| KQ.m@SHFE.rb | index | KQ.i@SHFE.rb |
| KQ.i@SHFE.rb | main | KQ.m@SHFE.rb |
| KQ.i@SHFE.rb | 跟随 | KQ.i@SHFE.rb |
| SHFE.rb2701 | main 或 index | SHFE.rb2701 |

例如 `chart.0.tq_series=index`、`chart.01.tq_series=index` 为非法窗口键；
`timeframes=30m&chart.2.tq_series=index` 越界；空值、重复键、`weighted`、`inherit`
均报错，不请求行情。已有 `/api/tq/fetch_ohlcv` 参数不变，只使用实际 symbol；
不把 chart_tq_series 或其他新字段传给后端。

下单面板查询到 BTC 仓位后切换为 ETH，该持仓与清理信息立即清空；切回 BTC 仍空，
需点击查询或在开启自动查询时打开下单确认框。若切换时旧清理尚未结束，只显示等待
提示并继续禁止本页开仓，完成后解除。下单 HTTP 接口不变。

## 测试、验证与阶段过渡

正式验证使用 `just check`、`just test`，后者包含逻辑、浏览器和各正式构建入口。
全部必须通过，不新增在线验证，不查询真实后端品种或交易账户。

逻辑测试覆盖双向前缀替换、缺省／同值、具体合约与非开头文本保持；URL 解析和
往返、旧默认、编号排序、所有非法等价类、布局增减、来源和自选保留。
验证具体合约或 CCXT 下修改形式不重取行情，主连与加权分流，相同实际身份仍共享；
窗口改变需求后旧流按现有生命周期取消，未改变的窗口不重新拉取历史或播种指标。

浏览器验证 TQ 区域控件与窗口周期对应、草稿应用／取消／恢复默认、URL 前后退及
刷新恢复、具体合约提示和忽略、来源切换保留，实际请求与标题一致；窗口换形式
保持画布实例，切回可复用已有流，非法 URL 在取数前失败。保留现有图表和交易回归。
验证持仓查询在同身份重开时保留、确认新品种及关闭期间导航时清空、切回不恢复、
来源切换与完整身份隔离；在途清理清空显示后仍阻止开仓，晚到结果／错误不恢复，
结束后正确解锁，已有交易日志和参数偏好保持。
不引入兼容双轨，无临时桥接或允许失败阶段。
