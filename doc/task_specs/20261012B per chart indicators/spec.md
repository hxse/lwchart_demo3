# 每窗口指标配置

## 任务边界

为 market 增加公共默认指标加窗口覆盖，设置、URL 与图表保持一致。
保留原 indicators 紧凑写法及公共默认值，沿用元数据、指标准入、共享图表、主图
占比、临时拖动、来源身份、自选 hash、URL 长度检查和浏览器导航。
不新增单窗口数据源、品种、历史数量、主题或主图占比，不扩展 legacy 配置。

窗口覆盖只属于页面设置与 query；TOML 继续提供公共默认指标，不增加逐窗口
TOML 字段。无覆盖的旧配置、runtime 和 URL 继续归一为全部窗口继承公共。
用户已明确的模式及窗口写法不能在实现时改为按周期识别或复制独立行情请求。

范围包括正式任务文档、配置与 UI、query、窗口展示需求、共享流并集、必要校验
与离线测试、current spec／guide。依赖版本、ADX 补丁、指标公式、行情协议和
部署行为不变；不新增在线测试、实际部署、SSH 操作或推送。
停止线：三种模式、窗口生命周期、共享并集与实例复用、真实图表及旧入口回归、
正式检查和构建通过。不能通过丢配置、重复请求、重算所有指标或放宽对齐交付。

## 任务规范

### 设置模型与继承

内部页面设置增加 chart_indicators，使用一基窗口编号到指标数组的稀疏映射。
键缺省表示继承公共 indicators；显式空数组表示无指标；非空数组表示独立配置。
缺省整个映射归一为空对象。显式 null、非对象、非规范窗口键或越界窗口拒绝。
每个公共／独立列表最多十二项，同列表配置重复拒绝，所有项复用共享参数与准入
校验；同一项出现在多个窗口合法。显式覆盖即使与当前公共内容相同也必须保留，
不能按值相等折叠成继承。

窗口按布局的行优先位置编号，不按周期或品种识别。修改周期保留该位置覆盖；
切数据源或自选保留全部有效窗口配置。缩减布局保留前 N 个窗口并移除其余覆盖，
新增窗口默认继承公共，前进后退可恢复原页面组合。query 覆盖按最终推断的布局
校验，不允许隐藏的越界配置。

### UI 与提交

菜单保留数据源和公共设置，公共“技术指标”明确表示公共默认值。窗口周期选择
移到独立窗口设置框，用窗口 Tab 切换；Tab 显示位置编号与当前周期。
活动窗口包含周期选择、指标模式：继承公共／独立配置／无指标。独立模式显示
复用的指标编辑器；继承显示公共草稿的当前列表，无指标不显示编辑框。

切换 Tab 或模式不提交、不取数；菜单内切回独立模式保留该窗口已编辑文本，首次
独立编辑以公共草稿预填。缩减布局丢弃已移除窗口草稿，新增窗口继承公共。
公共和窗口编辑共用能力提示、none、默认填入、参数解析，不维护不同指标入口。
统一应用校验所有当前有效配置；错误指出公共或具体窗口并保留原设置、URL 与
图表。继承模式下未使用的独立文本不参与提交。取消／关闭／Esc 丢弃全部草稿，
导航重置草稿，hash 自选保持独立。

### 计算与展示归属

共享流仍以来源身份、周期和历史数量识别，MarketHub 先汇总各窗口的生效列表，
按规范化指标键去重并排序，再对每个唯一流 configure 一次。所有同周期窗口复用
该流和一个 timer／请求，返回给窗口的顺序保持布局顺序。

公共默认仅对继承窗口产生计算需求；未被任何有效窗口使用的配置不创建实例。
用户列表的十二项限制保持；内部共享计算集合最多为最大窗口数乘十二，当前为
四十八，不把用户单列表上限套到并集上。两种规模复用同一参数和重复校验，不能
取消用户限制或增加备用计算链。

一项仍被任一窗口使用就保留实例；最后一个使用者移除才释放。同集合重新排序、
独立与继承之间同值切换不重播历史；新增／改参数只初始化新配置，其余累计状态
和起点保持。仅修改指标不重新请求完整行情；历史异常仍按现有协议重载。
计算失败继续保留已提交快照并暂停整个共享流，影响共享该流的窗口；不改为窗口
专属失败恢复。其它身份／周期流继续独立运行，不以关闭指标或忽略错误掩盖失败。

每个窗口仅按自己的生效列表生成系列、标签、图例和 Pane，数据补丁从共享结果中
读取对应子集；不绘制并集中的其它指标。颜色按该窗口列表顺序，显示规则读取同一
元数据。主图占比仍公共，副图均分以该窗口自己的数量为准；其它窗口保持实例与
临时高度，窗口自己的结构改变按主图占比预设重新分配。

## 公开接口与用户写法

公共 indicators 继续保存默认列表。窗口覆盖 query 为 chart.N.indicators，N 是
当前布局内一基整数，不接受零、前导零、负数、未知子字段、空值或重复参数。
覆盖值沿用分号分隔 DSL，none 表示明确无指标；缺参数表示继承公共。
完整 URL 始终保存原十五个基础参数，按编号追加零至四个显式覆盖参数，hash 不变。

```text
/?layout=2x2&timeframes=30m,4h,1d,1w&indicators=ema,14;ema,50&chart.1.indicators=ema,14;rsi,14&chart.2.indicators=macd,12,26,9&chart.4.indicators=none
```

此例窗口一使用 EMA14／RSI14，二使用 MACD，三继承公共 EMA14／50，四无指标。
序列化使用 URLSearchParams 百分号编码。公共列表改变只改变继承窗口的生效列表。
`?timeframes=30m,30m&chart.1.indicators=rsi,14&chart.2.indicators=macd,12,26,9`
表示同周期两图分别显示 RSI 和 MACD，共享一次取数及两项计算。

`?layout=1x1&chart.2.indicators=none` 越界，`chart.01.indicators` 非规范，
`chart.1.indicators=` 空值，十三项或同窗口重复配置都明确拒绝整个提交。
不新增后台接口、存储介质、指标 DSL、legacy 注记或图表专属硬编码。

## 测试、验证与阶段过渡

使用正式 `just check`、`just test`、`just market --build`；legacy 构建和声明
消费仍由现有离线浏览器入口执行，使用临时目录，不写用户 Notebook 导出。

- 缺省继承、独立同值保留、none、旧 URL、百分号编码和完整十五加覆盖参数；
  非法键／布局边界／重复／空值／参数／十二项限制按正确校验阶段失败。
- 窗口位置随周期修改、缩减／新增布局、数据源与自选保留、导航及 URL 长度限制；
  公共默认与独立值同时有效，TOML 继续只提供公共列表。
- 同周期四图不同列表的去重并集、至多四十八项、请求单飞、timer 与实例复用，
  每个流只 configure 一次；多窗口共有项的最后使用者释放，无未使用默认计算。
- 原生全量与并集增量逐时刻严格 Object.is 对齐，替换、追加、裁剪及全量重载；
  同集合顺序或同值模式变化不重算，新增配置不扰动其它实例累计起点。
- 共享流初始化／更新失败按现有模型隔离、保留快照、停止与删除失败项恢复；
  另一周期保持正常，未从所有使用者移除前不能误恢复。
- 真实 UI Tab、周期、三模式、草稿保留、取消、统一应用、错误及导航；绘图、标签、
  图例仅含窗口子集，none 只有主图，主图占比按各自副图数量生效。
- 改一个窗口不重复请求，其它窗口画布和临时高度保持；共享计算期间旧代次不能
  回写，现有严格指标、Pane、legacy、文件校验、部署及生成声明回归通过。

无阶段桥接或允许的必需失败；只有所有本任务必要验证通过后完成交付。
