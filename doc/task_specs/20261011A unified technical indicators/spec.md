# 技术指标统一

## 任务边界

交付一套指标元数据、一个 trading-signals 计算适配及两个入口共用的指标展示链路。
首批候选为 sma、ema、dema、tema、rsi、cci、macd、atr、adx、er、bbands。
逐指标准入；仅某指标的库计算不满足契约时可暂不开放该指标的 market 计算，
其元数据与 legacy 文件展示保留，不阻断其他指标及公共链路交付。
market 改为只覆盖旧末根和追加新根；历史异常或缺少旧末根直接重新请求完整窗口。
同步受影响的 current spec、guide、公开类型及生成声明，完成严格离线对齐与双入口验证。

计划新增模块位于 src/indicators/，按定义、参数、计算、展示职责组织；新增有效规范
计划为 doc/current_specs/indicators.md，由对应实施阶段交付并同步有效规范。
继续使用 LWChart、ChartController、SeriesRegistry、LegendManager 和既有取数 API。
保持两来源、身份隔离、单飞／取消、query／hash、自选、按钮栏、主题／时区、精确
视窗跟随、legacy 文件读取／Notebook 导出／箭头／风险线、回环部署及无后端独立启动。
不增加在线测试、交易操作、后台指标计算服务、日志上报接口或自定义公式 DSL。

须退出 src/crypto/data/EmaSeries.ts 的自研计算、检查点、canUpdate／历史重放逻辑，
CandleStore 的 emas 专用状态和旧 DataChange.emas、EMA 专用标签／配色分支、旧参数
校验副本及过时调用。旧 tests/unit/ema.test.ts、ema-reference.test.ts 的算法契约，
tests/fixtures/ema-reference.json、generate_ema_reference.py 及其有效文档引用，
在计算迁移时一起退出或由新测试取代；不保留生产或测试中的自写参考指标算法。
历史 task 文档不批量回改。共享图表仍有独立职责的 historicalUpdate 能力不因行情
协议改变而删除；普通文件列、通用系列、时间转换和显示格式化不属于旧指标算法。

停止线：统一框架完成，已开放指标沿唯一正式链路严格验证；无旧末根重叠必然
请求完整窗口；旧计算退出；暂不支持类型在设置／URL／TOML 中明确拒绝，保留
原因与离线最小复现，且不能静默删项、补零或使用备用算法。默认 EMA 必须可用。
只有问题能够确认局限于单指标时才允许暂不支持；参数解析、行情提交、副图、
多输出、图表生命周期、两入口或其他核心契约的问题必须修复，重大设计阻断
则暂停说明并确认。不能关闭指标以规避公共链路或必须通过的已开放指标回归。

## 任务规范

### 所有权与唯一链路

指标模块是指标知识的唯一所有者。每个定义包含 type／名称、参数与默认值、输入
字段、库构造配方、输出角色及结果映射、可用状态规则，以及下述完整显示元数据。
trading-signals 8.3.0 是首个准入候选，不再视为已经通过的交付版本。每个候选均用
package.json 精确版本和 bun.lock 保证离线测试可复现，未准入时仅用于正式测试，
不被生产计算调用。固定样本、合法边界及严格对齐通过后，才成为交付版本并迁移
生产计算。允许选择满足同一构造、输入、读取与显示契约的较新官方
发行版，必须同步版本与 fixture 来源；不使用 GitHub main、本地补丁或 fork。
逐项核查后仅开放通过的指标，使用同一个精确锁定官方版本。单指标失败保留
最小复现和不可用原因，可继续整体迁移；默认 EMA 或公共契约无法成立时停止。
不为通过准入保留旧算法，不在运行时自动检测／跳过错误或放宽数值断言。
构造／读取契约须在元数据阶段写定，执行适配与独立参考使用同一口径。

应用只选择构造参数、准备输入、调用库和读取原生结果，不实现 EMA／RSI 等公式，
不使用库的信号结果执行交易。采用准入版本的初始化、预热、平滑和 ER 定义，明确
退出原 SMA 播种 EMA 的数值约定。MACD 使用原生 histogram，不额外乘二。
直接计算定义为新建库实例，以完整输入从头重放并逐时刻读取公开结果；这不是
在旧实例上补几根。参考计算与增量计算使用同一版本、参数、输入字段及计算起点。

### 指标定义与参数

以下参数对象是规范化后的 IndicatorSpec，type 严格小写，不增设别名：

| type | 字段 | 默认参数 | 周期边界 |
| --- | --- | --- | --- |
| sma | period | 20 | 1..100000 |
| ema | period | 14 | 1..100000 |
| dema、tema | period | 20 | 1..100000 |
| rsi | period | 14 | 2..100000 |
| cci | period | 20 | 2..100000 |
| atr | period | 14 | 1..100000 |
| adx | period | 14 | 2..100000 |
| er | period | 10 | 2..100000 |
| macd | fast、slow、signal | 12、26、9 | 均为 1..100000，fast < slow |
| bbands | period、deviation | 20、2 | period 为 2..100000 |

deviation 为有限正数。对象不接受未知字段，字符串必须提供完整参数且数量正确；
不在 URL 中自动补单项缺失参数。空列表／none 表示无指标；十二实例上限和同配置
去重只约束 market 指标列表。market 计算实例按 type 与规范化参数识别；legacy
不计算导入列，文件组按单个 chart 内的 id 识别，不同 id 可使用相同参数。
同周期不同类型、同类型不同参数均可共存。参数校验和序列化只定义一次，
设置、TOML、query、计算器和 legacy 元数据适配复用它，不在图表重写校验。

结果属于某指标实例及输出角色，时间使用 UTC 毫秒；绘图边界转 UTC 秒一次。
单值指标输出 value，MACD 输出 macd／signal／histogram，布林带输出
lower／middle／upper。结果区分 warmup、value、undefined：尚不可用、有限值、
定义明确允许的合法未定义值。后者保留原生结果用于严格对齐，绘图显示缺口／
“未定义”，不补零、不连接缺口、不保留该时刻旧值，也不触发请求或重载。
数值零必须保留；无值及未定义也参与逐时刻状态对齐。合法未定义只允许元数据
逐项列明的结果，不得把所有 NaN 都吞掉。其他非有限值、缺字段或类型错误是
计算失败，不能改变原始数值或静默省略；固定样本与恢复边界在准入阶段检查。

### 正常行情与异常重载

每个行情状态仍按来源、真实身份、周期和 history_bars 隔离。初始请求完整数量，
有行情后每轮固定请求最新五根。保留最多最近五根已接收行情用于比较；显示窗口
不足五根时也保留这段有限数据，不能为此多请求初始历史或保存计算状态检查点。

先完成基础响应校验，再捕获更新前末根时间 T。若响应缺少 T，无论是否与更早
历史重叠，一律进入完整重载，不采用“有任意交集就可以增量”的旧规则。
响应含 T 时，对双方已知且早于 T 的记录严格比较完整 OHLCV；任意差异进入
完整重载。可比时间范围内出现未知历史插入也进入重载。不可比较的更早窗口外
记录不补进指标；期货休息、周末和节假日不按固定时间间隔判缺根或补造数据。

全部历史校验通过后，才覆盖 T 对应的行情，并对输入发生变化的指标调用 replace。
唯一生命周期例外：某实例自初始化以来只接收一根输入时，覆盖这根改用新原生
实例 add 修正后的唯一输入，避免 DX 首根 replace 把旧根当成前根。不是根据
显示窗口长度判断，不恢复检查点、不请求历史；两根及以上继续原生 replace。
随后按升序对新于 T 的每根调用 add。不对旧历史调用指标，不把旧末根当新根追加。
只改变 volume 时仍更新行情，但不重算不依赖 volume 的指标；high／low 变化
必须更新依赖这些字段的指标。相同批次再次返回跳过重复计算和绘图。

异常记录一次结构化 WARN：原因、来源、交易所（适用时）、品种、周期、旧末根
时间和差异字段／旧新值；不记录凭据或原始鉴权响应。合并在浏览器，默认输出
浏览器控制台。每轮最多额外请求一次 history_bars 完整数据，不循环追赶。

完整重载必须重新获取数据，不用旧窗口拼接该响应。校验新快照、为全部已配置
指标创建新实例、从头计算整段输入，成功后把行情、结果和计算器一起原子替换。
完整取数／响应校验失败保持原已提交行情／结果，下一轮直接请求完整窗口。非空快照的
末根早于已有行情时拒绝倒退；合法空快照同时清空行情与指标，下轮继续完整请求。
切身份或退出丢弃旧代次结果，保持请求单飞。意外计算失败不提交部分结果、不继续
使用已推进实例，保留已提交展示快照并停止该流的自动更新，显示指标与失败原因。
计算错误不被当作历史异常反复重载；用户移除问题指标、切换行情身份或明确重新
加载后才重新初始化；错误恢复重建全部可能受污染的实例并重置参考起点。
合法 undefined 不进入错误状态，后续仍正常追加与替换。

正常裁剪只移除窗口外行情显示点和指标显示点，保留库实例的连续计算状态。
修改指标配置仅初始化新增／参数改变的实例，输入为当前显示历史；其参考起点
也从此重置。未改变的指标继续使用原实例；主题、时区和布局不触发取数
或计算重置。初始、身份／数量变化及异常重载以新完整数据作为全部指标起点。

### 显示元数据与双入口

每个指标定义完整声明输出角色、图表原语、主图／独立 Pane、轴与缩放贡献、
标签模板、数值格式、颜色角色／主题配色、参考线、柱色策略、默认显隐／图例、
组内顺序和 Pane 高度权重。图表只处理通用原语和这些字段，不按指标名称或
数据列名分支决定显示；入口适配也不得再复制这些规则。

| 指标 | 默认位置 | 原语／轴／参考线 |
| --- | --- | --- |
| SMA、EMA、DEMA、TEMA | 主图 | 单 Line，价格轴；均线不扩张 market 蜡烛缩放范围 |
| 布林带 | 主图 | lower／middle／upper 三 Line，价格轴，上下轨纳入缩放 |
| RSI | 独立 Pane | 单 Line，自身轴，30／50／70 |
| CCI | 独立 Pane | 单 Line，自身轴，-100／0／100 |
| MACD | 独立 Pane | macd／signal 两 Line 与 Histogram，自身轴，0；四色柱 |
| ATR | 独立 Pane | 单 Line，自身轴，不与价格轴混用 |
| ADX | 独立 Pane | 仅 ADX 单 Line，自身轴，25 |
| ER | 独立 Pane | 单 Line，自身轴，0／0.5／1；标注选定库的实际 ER 定义 |

同一指标组共用 Pane、参数和稳定身份，组内角色分别命名及配色。market 本次不
新增临时组显隐；标签仍为展示文字，添加／删除配置与 none 沿现有设置入口。
删除配置释放实例及独占副图，再添加重新播种，不能称为“不重算的隐藏”。
Pane 共用时间轴，主图高度权重大于单个副图，副图按配置顺序分配；允许既有
分隔线拖动调整。价格、指标及比例格式来自元数据，图例与坐标轴一致。
默认仍为 EMA14／50／100，不自动开启全部指标，不额外实现布林带填充或 DI±。
market 系列键为 market/<规范化配置>/<output>，legacy 为 legacy/<id>/<output>，
均限定在单个 chart 内；不同 chart 的 registry 隔离。显示名独立于 key。
现有 SeriesConfig.name／SeriesDataPatch.name 继续承担键，新增可选 displayName
供图例等显示，未指定时显示 name；改主题／数据不重建图表。
复用既有 registry 管理 series、参考线和图例生命周期，更新／删除不得遗留对象。
实时补丁支持 Histogram，整批校验、蜡烛为主时间锚点与精确视窗行为继续有效。

legacy 读取文件现有数值，不在 TS 重新计算导入列。新增可选 indicator 注记，
对应下节的规范；没有注记的普通 line／histogram／volume 等保留通用数据映射。
显式文件配置的 Pane、样式、show 和 showInLegend 优先；按旧位置索引覆盖的写法
继续有效，先完成覆盖再生成默认展示。显式参考线含隐藏项参与默认线去重；
显式 histogramOpt.color 覆盖自动柱色，不能只覆盖系列选项却留下逐点自动 color。
关联与合并规则由共享展示职责统一拥有，不猜列名创造计算指标。既有四色柱及
参考线样式知识迁入指标模块，通用图表不保留 RSI 等专用名称分支。
共享样式类型不能继续依赖旧页面的 SeriesItemConfig／文件路径模型。

## 公开接口与用户写法

Just 命令及行情 API 路由不变，指标仍绑定 query 的 indicators，hash 自选不变。
保留 none 与 ema,14；新设置把“EMA 指标”改为通用“技术指标”，应用／取消／
前进后退、配置长度检查及书签语义保持。如下是完整紧凑写法：

```text
sma,20;ema,14;dema,20;tema,20;rsi,14;cci,20;macd,12,26,9;atr,14;adx,14;er,10;bbands,20,2
```

```toml
[dashboard]
indicators = ["ema,14", "rsi,14", "macd,12,26,9", "bbands,20,2"]
```

```text
/?indicators=ema%2C14%3Brsi%2C14%3Bmacd%2C12%2C26%2C9
```

规范化对象示例为 `{type:'ema',period:14}`、
`{type:'macd',fast:12,slow:26,signal:9}`、`{type:'bbands',period:20,deviation:2}`。
ema,0、rsi,1、macd,26,12,9、bbands,20,0、缺参数、未知类型和相同配置重复项
在请求或计算前明确拒绝，不能夹值、默认补参数或保留旧解析副本。

legacy 的 SeriesItemConfig 增加可选 indicator：
`{id,spec,output}`。id 为同一 chart 内的组标识，匹配
`[A-Za-z][A-Za-z0-9_-]{0,63}`；spec 使用上述对象，output 属于该定义的角色。
同组 spec 与 Pane 必须一致，角色不能重复；允许仅展示组内部分输出。
不同 id 的相同参数、相同 output 合法，不受 market 列表去重与十二实例上限限制。
原 type 必须匹配该角色原语，普通配置未加注记时完全合法。例如副图中的一项：

```json
{
  "type": "histogram", "fileName": "indicators.csv", "dataName": "macd_hist",
  "show": true, "showInLegend": true,
  "indicator": {
    "id": "macd-main",
    "spec": {"type": "macd", "fast": 12, "slow": 26, "signal": 9},
    "output": "histogram"
  }
}
```

同组 Line 项分别绑定 output=macd／signal 和对应文件列；配置位置继续决定 Pane。
未知 output、角色与 type 不匹配、组内 spec 不一致明确报错，并定位 slot／pane／项。
独立 hline 新增可选 referenceFor=<同 chart 内的指标组 id>，用于明确关联参考线；
不指定时仍保留普通参考线。其覆盖／共存规则在展示阶段冻结，不增加 market 显隐参数。
原 LWChart／Notebook 导出保持；SeriesDataPatch 扩展 Histogram 的单值及 color
及 Line／Histogram 的 time-only 缺口补丁，displayName 声明同步。
不新增对外发布的计算 SDK、插件注册或运行时公式接口。

## 测试、验证与阶段过渡

代码实施使用现有宿主 Bun、正式 just check 与 just test，均默认离线。
图表／入口集成和最终验收再使用 just market --build；legacy ES／UMD 及复制
通过现有浏览器 fixture 的正式临时目标链路验证，不写入用户真实 Notebook 目录。
不为新算法的测试引入 Python／真实行情或在线服务；生产部署不在本任务授权内。

第一阶段建立元数据与参数唯一来源，并把现有 EMA 的显示读取接到它；公开 market
暂保留 EMA 类型子集，计算仍只有现有实现。后续计算阶段先逐项完成指标准入，
再以合格版本切换行情与计算调用方、删除旧实现及旧参考链路。
公开类型子集暂不扩大；不出现两个生产
算法并行运行。显示／入口阶段启用已准入 market 类型及全部候选的 legacy 注记，退出临时子集门卫与
数据桥接。有限类型转发或旧数据结构适配只能服务上述过渡，不包含任何指标公式，
必须有明确调用方且在相应替换阶段同时删除。每阶段正式入口可用，无允许失败。

计算阶段承接全部十一指标的固定结果、合法边界、恢复行为、整批更新、全量重载
和严格对齐逐项准入，保留不通过指标的证据；显示阶段承接元数据驱动与公共写法；集成阶段复核已准入样本，
承接两入口、浏览器及构建边界，不等开放全部指标后才首次检查库可靠性。
主任务不重复子阶段已经承担的验证，不建立手工执行／验收记录。

对齐基准直接构造第三方实例，不调用应用计算引擎或自研算法。每个断言点将同一
计算起点以来的完整模拟输入（末根使用最终修正值）从头喂给新实例，逐时刻读取
库公开结果，与应用 replace／add 结果比较。裁剪时参考保留该起点全部输入，
只截取相同显示窗口；重载和新指标初始化重置对应参考起点，不能用滚动窗口
重新播种冒充连续计算。不存在直接批量 API 的指标同样用新实例完整重放。

所有时间、点数、输出角色、预热／无值状态及每个原始数值严格一致，数值使用
Object.is 或同等严格断言，不采用 epsilon、toBeCloseTo、显示取整或人为修正。
